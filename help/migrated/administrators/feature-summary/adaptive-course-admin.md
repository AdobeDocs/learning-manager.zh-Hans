# Adobe Learning Manager中的自适应课程

Adobe Learning Manager中的自适应课程让您可以根据每个学习者所属的用户组来控制他们查看的模块以及所需的模块，从而向多个受众交付一门课程。

单个自适应课程不会为每个角色、区域或合规性配置文件构建单独的课程，而是向正确的学习者动态提供适当的内容。

## 自适应课程可以解决什么问题

培训庞大、多元化劳动力的组织面临共同挑战：数据隐私、工作场所道德和安全必须覆盖具有不同角色、地点或合规性义务的学习者。

这造成了重复：作者维护多个几乎相同的课程，报告非常零散，当核心内容发生变化时，每个副本都需要更新。

自适应课程通过让作者在模块级别配置与用户组关联的可视性和完成规则，解决了这一问题。 一门课程可同时服务于每位受众。

### 常见情景

- 合规性课程包含面向所有员工的核心模块以及特定于司法辖区的附录模块。 每个学习者只能看到适用于其位置的附录。
- 新员工课程向员工、经理和承包商显示不同的模块。 每个角色只查看与其相关的内容。
- 年中时，安全课程会添加新的必修模块。 管理员会触发刷新完成，因此所有以前完成的学习者都必须执行新模块才能保持合规性。

### 真实示例

组织向全体员工推出强制性合规性课程。 本课程包含七个模块：

- 两个模块适用于所有员工。
- 两个模块仅适用于人员经理。
- 两个模块仅适用于担任技术角色的单个投稿人。
- 一个模块仅适用于高级董事及以上。

## 模块可见性和完成工作方式

自适应课程中的每个内容模块都有两个设置：

**可见：**&#x200B;可以看到模块的用户组。 这些组中的学习者可以在课程中看到该模块，并可以访问它，但除非他们同时处于&#x200B;**&#x200B;**&#x200B;的必修状态，否则该模块不算完成。

**必修：**&#x200B;需要模块才能完成课程的用户组。 在&#x200B;**&#x200B;**&#x200B;强制下列出的模块对这些组自动可见；您无需将相同的组添加到两个设置中。

在任何时间点，任何给定学习者的模块均处于以下三种状态之一：

| 状态 | 确定方式 | 是否计算完成？ |
|---|---|---|
| 必选 | 学习者属于在&#x200B;**&#x200B;**&#x200B;中列出的用户组 | 是 — 必须完成 |
| 可选 | 学习者位于&#x200B;**&#x200B;**&#x200B;以下的组中，但非&#x200B;**&#x200B;**&#x200B;必修 | 否 — 可见且可访问，但不是必需的 |
| 隐藏 | 学习者不在任一设置下的任何组中 | 学习者完全看不见 |

## 自适应课程的特点

自适应课程的特征是课程会持续评估学习者的个人资料，而不仅仅是在注册时。

学习者的用户组在注册期间发生更改时：

- 不再在其新用户组下可见的模块会立即消失。
- 如果新可见模块对于其新用户组是必需的，则会将其添加到其完成要求中。
- 如果以前的必修模块不再是必修模块，则会从其完成要求中将其删除。
- 以前完成的模块仍然已完成。 配置文件更改不会重置已完成的工作。

### 自动取消注册

如果更改用户组后，所有学习者的必修模块均移除，则学习者会自动取消课程注册。

### 自动完成

如果用户组更改删除了进行中学习者所有剩余的不完整必修模块，则课程会自动为该学习者完成。

如果配置文件更改导致学习者尚未完成新的必修模块，管理员可以触发刷新完成操作以回滚现有的完成模块，并要求学习者完成新的模块。

## 哪些方面会适应，哪些方面会保持不变

自适应规则仅应用于&#x200B;**内容模块**。 以下内容适用于所有已注册的学习者（不考虑用户组）：

- **准备工作模块：**&#x200B;在核心内容开始之前向所有学习者显示。
- **测试模块：**&#x200B;可供所有学习者使用；无论内容模块状态如何，完成测试都会完成课程。
- **先决条件：**&#x200B;如果课程配置了先决条件，则所有学习者在注册之前都必须满足这些先决条件，无论其用户组如何。 必备项不是自适应的，无法限定为特定用户组的范围。

工作辅助和课程附带的资源也不适应。 所有已注册的学习者都可以看到这些内容。

技能、游戏点数和徽章会根据学习者第一门课程的完成情况授予，并且不受配置文件更改导致的重新完成情况的影响。

>[!NOTE]
>
>当自适应课程是外部共享的高级学习对象的一部分时，自适应课程将作为常规课程复制到子帐户中。


## 功能可用性

自适应课程功能由两级帐户级别标志控制。 请联系您的Adobe客户团队，以便为您的帐户启用此功能。

启用帐户标志后：

- 在创建或编辑课程时，**完成和可见性规则**&#x200B;切换变为可用。
- 启用切换开关会激活自适应配置面板。

**注意：**&#x200B;启用自适应功能标志为&#x200B;**不可逆**。 在帐户级别启用后，将无法禁用该选项。

## 目录共享

自适应课程可添加到您帐户内的目录中。 当目录与配对帐户外部共享时，自适应课程会自动从共享内容中排除。

>[!NOTE]
>
>在外部共享包含自适应课程的学习路径或认证时，接收帐户会在其目录中看到学习路径或认证，但不会显示其中的自适应课程。 学习对象没有被完全排除；只有自适应课程组件才会从共享版本中删除。 接收帐户中的作者应知道共享学习对象的模块可能少于源版本。

## 支持的配置

| 配置 | 是否支持？ |
|---|---|
| 常规学习路径中的自适应课程 | 是（请参阅下面的注释） |
| 灵活学习路径中的自适应课程 | 是 |
| 自适应学习路径中的自适应课程 | 否 |
| 认证中的自适应课程 | 是（建议不要用于重复认证） |
| 多注册 | 否 |
| 实例切换 | 是 |
| 目录共享（跨帐户） | 否 |
| 预习或测试模块的可视性规则 | 否 |
| 关于核心内容模块的可视性规则 | 是 |

>[!NOTE]
>
>在&#x200B;**有序**&#x200B;学习路径中包括自适应课程时，由于用户组与任何模块的可见性规则都不匹配，因此在自适应课程中没有显示模块的学习者无法完成该课程。 在有序学习路径中，这将阻止访问所有后续项目。 要避免此问题，请确保注册学习路径的所有学习者都属于至少一个用户组，该用户组对路径中任何自适应课程中的至少一个模块具有可见性。

此外，不要将包含自适应课程的学习路径嵌入到高阶（嵌套）学习路径中。 在此配置中，如果学习者在自适应课程中没有可见或必需的模块，则嵌入式播放器可能会变得无响应，从而阻止浏览其余内容。 此行为将在未来版本中加以解决。

>[!NOTE]
>
>当学习者在&#x200B;**常规**&#x200B;学习路径中自动取消注册自适应课程时，因为用户组更改移除了其所有可见模块，父级学习路径将保持注册状态。 学习路径不会自动取消注册。 即使其中的自适应课程无法再访问，学习者仍会在成绩单中看到学习路径已注册。 如果您的用例要求在自适应课程同时取消注册父学习路径，请考虑使用&#x200B;**自适应学习路径**&#x200B;而不是常规学习路径来包含自适应课程。

## 为您的帐户启用自适应课程

打开自适应学习，以便作者可以根据用户组成员资格创建向不同学习者显示不同模块的课程。

## 启用之前

- **永久：**&#x200B;启用后，无法为帐户关闭自适应学习。
- **同时影响课程和学习路径：**&#x200B;启用自适应课程的同一标记也会启用自适应学习路径。
- **现有课程保持不变：**&#x200B;只有新创建的课程才能进行自适应调整。 现有的常规课程不会自动转换。
- **作者会立即看到此选项：**&#x200B;保存后，自适应课程类型即会显示在创作工作流程中。
- **双层配置：**&#x200B;如果您的帐户已针对自适应学习进行了配置，您会看到该选项已启用且已锁定。 无法从UI更改它。 如果尚未设置帐户，则根本看不到该设置。 联系Adobe以请求设置。

## 启用自适应课程

1. 以管理员身份登录Adobe Learning Manager 。
2. 在左侧导览窗格中选择&#x200B;**设置**。
3. 选择&#x200B;**常规**。
4. 导航到&#x200B;**可见性和完成规则**&#x200B;部分。 如果您的组织已启用自适应学习，则该选项将显示为已锁定，如下所示：

![](assets/image_0001.png)

自适应学习现在对您的帐户处于活动状态。 作者可以立即创建自适应课程和自适应学习路径。

## 启用后有何变化

启用自适应学习后：

- 除现有的常规课程类型外，作者在创建课程时还会看到&#x200B;**内容可见性和完成规则**&#x200B;选项。
- 自适应课程中的每个内容模块都可以针对用户组使用&#x200B;**可选**&#x200B;和&#x200B;**必修**&#x200B;规则进行配置。
- 注册自适应课程的学习者只能看到其用户组显示的模块。
- 所有现有的常规课程保持不变。

## 故障排除

- **可见性和完成规则部分在设置中不可见：**&#x200B;在显示切换之前，必须在后端设置该功能。 请联系您的Adobe客户代表或Adobe支持以请求获取访问权限。
- **该切换功能已启用且似乎已锁定：**&#x200B;设置帐户时已启用自适应学习。 无需任何操作。 作者可以创建自适应课程。
