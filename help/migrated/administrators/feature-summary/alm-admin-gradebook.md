# 启用帐户的gradebook可见性

## 概述

管理员必须在帐户级别启用“成绩单”可见性设置，作者才能向课程中的学习者显示“成绩单”。 此设置用作主开关：关闭此设置后，学习者无论如何配置各个课程，都无法在任何课程中查看成绩单。

## 此设置控制什么

“**设置**”>“**常规**”中的“**渐变画册可见性**”设置确定是否允许作者在课程级别向学习者公开渐变画册。

| 设置状态 | 效果 |
| --- | --- |
| 已启用 | 作者可以使用课程编辑器中的&#x200B;**向学习者显示成绩单**&#x200B;选项，控制每个课程的成绩单可见性。 学习者可以在作者启用的课程中看到&#x200B;**Gradebook**&#x200B;选项卡。 |
| 已禁用 | 学习者无法在任何课程中查看成绩单。 如果禁用此设置，课程配置将无法向学习者显示成绩单。 |


这意味着帐户级别设置和课程级别设置协同工作。 学习者若要查看成绩单，必须同时启用这两个选项。

## 启用渐变书可见性

1. 以管理员身份登录Adobe Learning Manager 。
2. 在左侧导航栏中，选择&#x200B;**设置**。
3. 选择&#x200B;**常规**。
4. 滚动到&#x200B;**渐变书可见性**&#x200B;部分。
5. 选中&#x200B;**为学习者启用Gradebook视图**&#x200B;复选框。

   ![](assets/gradebook-admin-1.png)

作者现在可以配置每个课程的渐变画册可见性。

## 对作者工作流程的影响

启用此帐户级别设置后，课程编辑器中的&#x200B;**“向学习者显示成绩单”**&#x200B;切换开关可用。 作者使用此切换按钮可根据课程确定学习者是否可以看到&#x200B;**Gradebook**&#x200B;选项卡。

如果禁用此帐户级别设置：

* 可能仍会在课程编辑器中显示&#x200B;**向学习者显示成绩单**&#x200B;切换开关，但任何课程级别配置都将被覆盖。 学习者看不到成绩单。
* Gradebook分数和加权计算继续在后台运行，以便管理员报告。
* 管理员和自定义管理员仍然可以下载包含成绩单数据的学习者成绩单。

>[!NOTE]
>
>在帐户级别禁用此设置不会删除任何渐变簿配置或分数。 如果重新启用，则之前配置的所有课程级成绩单设置将立即恢复。

## 两种设置的交互方式

| 帐户级别设置 | 课程级别设置 | 学习者看到的内容 |
| --- | --- | --- |
| 已启用 | 向学习者显示Gradebook： **On** | 在课程播放器中可见&#x200B;**Gradebook**&#x200B;选项卡 |
| 已启用 | 向学习者显示Gradebook： **关闭** | 无“Gradebook”选项卡；仅内部计算分数 |
