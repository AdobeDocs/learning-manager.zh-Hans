# Adobe Learning Manager中的席位共享和帐户计划

席位共享允许一个帐户与其他帐户共享其部分许可席位，因此接收帐户中的学习者可以使用共享帐户中的席位访问Adobe Learning Manager。 哪些帐户可以共享名额，并与谁共享名额，取决于每个帐户使用的计费计划。

## 哪些计划支持席位共享

席位共享适用于&#x200B;**Ultimate**&#x200B;计划中的帐户。 **Prime**&#x200B;计划的帐户无法与其他帐户共享名额，并且无法从其他帐户接收共享名额。

默认情况下，通过信用卡计费的帐户位于Prime计划中，因此无资格参与席位共享。

试用帐户仅有一个例外：试用帐户可以从终极帐户接收共享名额。 在具备主动共享关系的情况下，试用帐户可访问最终级别的功能。

## 配对帐户设置可见性

配对帐户设置将在共享此功能的帐户的管理员应用程序中可见。

>[!NOTE]
>
>如果您的帐户与您获得名额的帐户之外的其他帐户共享名额，例如，如果您的帐户将共享访问权限传递给第三个帐户，则该链中的每个帐户都必须加入“最终共享计划”才能继续端到端工作。

## 支持席位共享的帐户组合

下表显示了在不同帐户计划组合之间是否可以共享席位。

| 共享帐户（父） | 接收帐户（子） | 是否支持共享？ |
|---|---|---|
| Prime（任何） | 任何 | 否，席位共享仅限终极计划帐户 |
| Ultimate | Ultimate | 是 |
| Ultimate | 的权限， | 否，计划不匹配 |
| Ultimate | 信用卡记帐帐户 | 否，计划不匹配，因为信用卡计费帐户位于Prime计划中 |
| Ultimate | 试用版 | 是的，当关系处于活动状态时，试用帐户可获得最终级别的访问权限 |

>[!NOTE]
>
>例如，根据帐户订阅的原始设置，可能会独立于计划类型对特定帐户配置之间的席位共享施加一些附加限制。 如果您无法在两个旗舰帐户之间建立共享关系，请联系Adobe支持以确认您的帐户配置。

## 计划更改后席位共享会发生什么

席位共享资格在续订时进行评估。 如果帐户的计划更改方式影响现有共享关系，则会出现以下情况：

* 如果共享（父）帐户的计划在续订时从Ultimate更改为Prime，则其现有席位共享关系终止。
* 如果接收帐户拥有自己的独立订阅，则该订阅不受影响；只有共享关系本身终止。
* 如果接收帐户是依赖父帐户的Ultimate访问权限的试用帐户，则在共享关系结束后，它将恢复到Prime级别访问权限。

这些更改将在帐户下一次续订现有ALM帐户时生效，而不是在有效合同期内立即生效。 但是，这些不适用于在分层功能启用后创建的新帐户。

>[!NOTE]
>
>当前具有最终级别访问权限的信用卡计费帐户将从下次续订开始移至Prime计划。 如果此时此类帐户存在任何有效的席位共享关系，则这些关系将作为同一过渡的一部分结束。
