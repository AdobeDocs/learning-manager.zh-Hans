# 面向作者的成绩单

## 为课程配置Gradebook

在Adobe Learning Manager中为课程设置加权分数，以便每个学习者都能收到根据其模块性能计算出的总分数，并能将课程完成情况与达到最低分数阈值联系起来。

创建新课程时，将在课程级别配置“Gradebook”。 无法将其添加到现有已发布的课程中。

>[!NOTE]
>
>若要让学习者查看课程中的Gradebook，管理员必须首先在帐户级别启用&#x200B;**Gradebook可见性**。

### 为课程启用Gradebook

* 以作者身份登录Adobe Learning Manager 。
* 在左侧导航栏中，选择&#x200B;**课程**，然后选择&#x200B;**添加**&#x200B;以创建新课程。
* 输入课程名称、描述和其他必需的详细信息。
* 在&#x200B;**模块**&#x200B;部分中，找到&#x200B;**Gradebook**&#x200B;切换开关。

  ![](assets/image_0003.png)

* 选择“**Gradebook**”切换开关以启用它。 下面将显示两个选项。 默认情况下，这两个选项均处于启用状态：
  * **向学习者显示成绩单：**&#x200B;学习者在课程播放器中看到&#x200B;**成绩单**&#x200B;选项卡，其中显示其模块分数、加权细分和聚合结果。 关闭此选项可在内部计算成绩，而无需向学习者公开成绩。
  * **包含不为最终成绩做出贡献的模块：**&#x200B;不可评分的模块（PDF、视频、音频等）显示在成绩簿中。 不可评分模块对学习者最终分数没有影响。

### 添加模块并分配权重

启用Gradebook后，添加内容模块并为每个可评分模块分配权重百分比。 在保存配置之前，重量百分比最多必须相加100。

* 选择&#x200B;**添加模块**。
* 在模块选择器中，选择要添加的模块并选择&#x200B;**添加**。 模块显示在&#x200B;**内容**&#x200B;部分。 可评分模块、SCORM、Captivate内容、AICC、xAPI、本机测验、活动模块、教室会话和虚拟教室会话，显示&#x200B;**权重**&#x200B;输入字段。 不可评分模块在权重列中显示破折号。
* 在每个可评分模块的&#x200B;**权重**&#x200B;字段中输入百分比值。 **总重量**&#x200B;指示器会随着您键入而更新，必须正好达到&#x200B;**100%**&#x200B;才能保存。

  ![](assets/image_0004.png)

* 对于具有多个传递类型的模块：仅当模块中的&#x200B;**所有**&#x200B;传递类型都支持评分时，才能分配权重。 如果任何一个交付类型不支持评分，则无法对整个模块进行加权。

>[!NOTE]
>
>评分等级不需要跨交付类型匹配。 一次课堂课程得分为100，一次SCORM模块得分为10，可以在同一个Gradebook中共存。 公式会自动规范化每个贡献。

### 设置最低及格分数

* 在课程编辑器中，找到&#x200B;**通过标准**&#x200B;部分。
* 在&#x200B;**跨模块的最低聚合分数**&#x200B;字段中，输入介于0到100之间的百分比。
* 值&#x200B;**0**&#x200B;表示课程仅基于所需的模块完成情况完成，没有总分阈值。
* 任何高于0的值均表示学习者必须完成所需模块且达到或超过此总分。
* 在&#x200B;**必修模块**&#x200B;字段中，输入所需的编号或从下拉菜单中选择所需的编号。

  ![](assets/image_0005.png)

* 选择&#x200B;**“保存”**。

最低及格分数可在&#x200B;**Gradebook**&#x200B;选项卡中向学习者显示，以便他们在开始学习之前了解阈值。

### 为多次尝试的模块配置分数设置 {#configurescoresettingsmultipleattempts}

如果模块允许多次尝试，请选择在Gradebook计算中使用的尝试分数。

* 在课程编辑器中，找到已启用多次尝试的模块。

  ![](assets/image_0006.png)

* 在该模块旁找到要使用的&#x200B;**分数**&#x200B;设置。
* 选择&#x200B;**最新**&#x200B;或&#x200B;**最高**：
  * **最新：**&#x200B;始终使用最近的尝试分数。 稍后尝试的分数越低，将取代较早尝试的分数。
  * **最高：**&#x200B;保留任何尝试中的最佳分数。 在以后的尝试中得分较低并不会降低存储的得分。

    ![](assets/image_0007.png)

* 选择&#x200B;**“保存”**。

### Publish课程

配置所有“Gradebook”设置后，使用标准工作流程发布课程。 选择“**保存**”，然后选择“**Publish**”以使课程可供学习者使用。

### 最佳实践

* 分配反映每个模块相对重要性的权重。 提高对学习目标至关重要的模块百分比。
* 启用&#x200B;**向学习者显示Gradebook**，除非有特定原因隐藏分数。 能够看到自己的体重和跑步分数的学习者能更好地排定其努力的优先顺序。
* 设置学习者注册之前的最低及格分数。 在有效注册后更改它可能会影响正在进行的完成。
* 在模块为评估时，如果学习者希望重试，则将&#x200B;**最高**&#x200B;用于多次尝试设置。 如果您希望捕获当前知识水平而不是最佳性能，请使用&#x200B;**最新**。
* 在保存之前，验证&#x200B;**总重量**&#x200B;指示器是否准确显示100%。
