# 添加页眉和页脚

添加页眉和页脚以包含徽标等元素。

1. 从工具栏中选择&#x200B;**主题**，然后将鼠标悬停在已应用的主题上，然后选择&#x200B;**编辑**。

2. 打开&#x200B;**添加标头**&#x200B;切换开关，以向课程添加标头。
   ![“编辑主题”面板中的“添加页眉”和“添加页脚”开关](../assets/39_edit_theme_header_footer_toggles_updated.png)

3. 在&#x200B;**徽标**&#x200B;下，选择&#x200B;**添加**&#x200B;以上传标题的徽标。

4. 打开&#x200B;**添加页脚**&#x200B;切换开关以将页脚添加到您的课程。

>[!NOTE]
>
>内容书写器会在您进行更改时自动在画布中预览这些更改。
