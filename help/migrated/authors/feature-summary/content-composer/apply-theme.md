# 应用主题

课程主题控制整个课程中的字体、颜色、页眉、页脚和组件样式。

将主题应用于您的课程，无需任何自定义即可实现快速、优美且一致的外观。

1. 从工具栏中选择&#x200B;**主题**。 **课程主题**&#x200B;面板将打开，显示所有可用主题。
   ![](../assets/34_course_themes_panel_open_updated.png)

2. 浏览可用主题：

   1. **默认：**&#x200B;显示Content Composer附带的内置主题。

   2. **自定义：**&#x200B;显示您已创建并保存的主题。

   3. 使用&#x200B;**搜索**&#x200B;栏按名称查找主题。

3. 选择要应用的主题。 课程预览会自动更新。
