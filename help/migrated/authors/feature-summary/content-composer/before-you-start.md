# 开始之前

在启动Adobe Learning Manager Content Composer之前，请确认以下各项：

>[!IMPORTANT]
>
>您必须使用有效的Adobe Creative Cloud帐户登录。 如果您还没有免费帐户，可以通过Adobe Express创建一个免费帐户。 有关详细信息，请参阅[创建免费Adobe Express帐户](https://helpx.adobe.com/express/web/adobe-express-subscription/free.html)。 创建Adobe凭据后，启动Content Composer并登录以开始创建课程。 如果您的组织已有Creative Cloud订阅，请联系您的管理员，以便在登录到Content Composer之前为您预配Creative Cloud帐户。

为获得最佳内容书写器体验，建议使用&#x200B;**Google Chrome**。 Firefox和Safari可能在功能或行为上存在差异。

## 内容书写器中的“帐户”菜单和首选项

访问Adobe帐户设置，设置显示首选项，并从Content Composer帐户菜单中打开最近的项目。

Content Composer工具栏包含Adobe通用导航帐户菜单。 使用它可以调整您的显示主题和语言，并快速重新打开您最近处理的项目。

### 打开帐户菜单

选择Content Composer工具栏右上角的配置文件图标以打开帐户菜单。

1. 设置首选项
2. 选择您的个人资料图标以打开帐户菜单。
3. 选择[!UICONTROL 首选项]。 将打开[!UICONTROL 首选项]对话框。
4. 在“[!UICONTROL 主题]”下，选择“[!UICONTROL 浅色]”或“[!UICONTROL 深色]”以设置Content Composer界面的显示模式。
5. 在[!UICONTROL 语言]下，选择您首选的显示语言。
6. 选择[!UICONTROL 保存]以应用更改。

>[!NOTE]
>
>主题和语言首选项仅适用于内容编辑器界面。 它们不会影响课程的视觉主题或课程内容的语言。

## 打开最近的项目

帐户菜单包含一个[!UICONTROL 最近]列表，其中显示您最近打开的Content Composer项目。

选择[!UICONTROL 最近]列表中的任何项目以直接打开它。

## 可选要求

* 您对要覆盖的主题区域有一个大致的了解。 在开始之前，您不需要完全清晰明了。

* AI可指导您通过对话定义课程标题、受众和学习目标。

* 源文档是可选的。 您无需上传任何文件即可继续，AI将根据您的输入生成内容。

* 如果您已有现有材料，并且希望课程从中进行绘制，则可以在简短阶段中上传该课程。 支持的文件格式包括PDF、Markdown (.md)、PowerPoint (.pptx)等，每种格式最大100 MB。
