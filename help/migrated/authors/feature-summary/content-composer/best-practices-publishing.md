# 从内容书写器发布到ALM的最佳实践

- 在生成大纲之前，请先编写特定的学习目标。 目标控制AI在源文件中的优先顺序、大纲结构以及测试内容。

- 在生成课程之前查看大纲。 在大纲阶段通过聊天更改课程名称需要几秒钟的时间；生成后更改这些名称需要返回大纲对话。

- 在需要准确执行组织的特定过程时，启用&#x200B;**限制输出到文件中的内容**。 例如，用于合规性或政策培训。

- 在发布之前查看所有生成的内容、评估和学习目标。 AI输出是概率性的，并且可能因代际而异。

- 当修复的“课程”>“主题”层次结构对您的深度粒度不足时，使用&#x200B;**折叠面板**&#x200B;和&#x200B;**选项卡**&#x200B;组件可在主题中添加内容。
