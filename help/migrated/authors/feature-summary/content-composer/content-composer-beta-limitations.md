# Adobe Learning Manager Content Composer Beta版限制

当前Content Composer Beta版限制的完整列表，其中包括可用说明和解决方法。

## 当前限制

下表介绍了当前Beta版中的所有已知限制。

| **限制** | **描述** | **解决方法** |
|---------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **大纲编辑仅供对话** | 无法在画布上选择课程或主题来重命名、重新排序或删除它。 所有大纲更改都必须通过助理聊天面板进行。 | 询问助理：“将第2课重命名为‘密码安全’”或“将主题1.3移到第2课”。 |
| **大纲层次结构已修复** | 课程结构修复为“课程”>“主题”。 无法创建子主题、其他层次结构级别或自定义结构。 | 使用可用组件在主题中添加深度。 |
| **在生成课程后无法直接编辑大纲** | 课程生成后，主题名称和课程名称仍保留在大纲结构中。 您必须返回大纲级对话才能更改它们。 不能通过在课程编辑器中选择一个标题来重命名它们。 | 在课程编辑器中询问助理：“将第3课重命名为‘Incident Response’。” |
| **评估类型：仅限MCQ和True/False** | 当前测试版仅支持选择题(**MCQ**)和True/False问题。 其他评估类型不可用。 | - |
| **试题库不可用** | 您无法导入或管理预先编写的问题库。 | 用对话方式构建其他问题：“在第1课的测验中再添加两个问题。” |
| **知识检查未评分** | 课程中的知识检查没有评分。 系统只会评分和记录课程结束测验的测验评估。 | 对必须生成完成或分数记录的任何评估使用测验（而非知识检查）。 |
| **对话操作仅限于支持的功能** | 助理可以自由讨论和集思广益，但实际课程修改仅限于产品支持的功能。 生成不受支持的内容结构或格式的请求可能无法成功。 | 如果请求不起作用，请让助理解释其可以执行的操作。 |
| **文档受限的生成** | 启用&#x200B;**“限制输出到文件中的内容”**&#x200B;后，Content Composer将仅从已上载的源文档生成内容。 它不会提供这些来源以外的信息。 | 禁用此切换可允许AI补充一般知识。 |
| **协作功能在不断发展** | “共享以供审阅”、“注释”和“共享以供学习者使用”均处于积极开发阶段。 在正式发布之前，实施详细信息可能会更改。 | 使用&#x200B;**复制链接**&#x200B;共享预览链接以进行非正式审阅。 对于协同编辑，与协作者协调轮换。 不支持同时协同编辑。 |
| **产品内助理不是产品帮助系统** | 会话助手专为课程编辑任务（如生成和修改内容）而设计。 对产品使用问题的响应可能不可靠，因为尚未明确设计此行为。 | 对于操作方法问题，请使用现有的帮助文档，而不是询问产品内部助理。 |
