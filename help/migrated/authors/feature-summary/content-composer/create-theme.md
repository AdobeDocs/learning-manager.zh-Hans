# 创建主题

创建自定义主题的两种方法，两种方法都会将结果添加到&#x200B;**自定义**&#x200B;主题列表中：

- 使用工具栏中的&#x200B;**创建**&#x200B;选项&#x200B;**从头开始构建** — 配置调色板、字体和其他属性，然后&#x200B;**另存为新内容**。

- **导入自定义JSON文件** — 将现有主题导出为JSON，在文本或代码编辑器中编辑它，然后将其重新导入。

**需要更多控制？**

有关按元素排版（课程名称、主题名称、块标题、字幕）、颜色令牌级别自定义以及完整JSON架构访问权限（平台或品牌团队通常希望获得的控制类型），请参阅[高级主题自定义](advanced-theme-customization.md)。

## 从头开始创建主题

1. 从工具栏中选择&#x200B;**创建**&#x200B;以打开&#x200B;**课程主题**&#x200B;面板。
   ![](../assets/44_course_themes_create_button_updated.png)

2. 根据需要配置主题的调色板、字体和其他属性。
   ![](../assets/45_create_theme_panel_name_palette_fonts_updated.png)

3. 选择“**另存为新内容**”以将该主题添加到您的“**自定义**”主题列表中。
   ![](../assets/46_custom_themes_list_new_theme_added_updated.png)

## 通过导入JSON创建主题

1. 从工具栏中选择&#x200B;**主题**&#x200B;以打开&#x200B;**课程主题**&#x200B;面板。

2. 将鼠标悬停在要用作基底的主题上，然后选择&#x200B;**导出**&#x200B;以将其下载为JSON文件。

3. 在文本或代码编辑器中打开JSON文件，并更新其属性，如半径、间距、调色板或字体。

4. 保存JSON文件。

5. 在内容编辑器中，从&#x200B;**课程主题**&#x200B;面板中选择&#x200B;**导入**。

6. 从您的计算机中选择更新的JSON文件。

7. 选择“**另存为新内容**”以将该主题添加到您的“**自定义**”主题列表中。
