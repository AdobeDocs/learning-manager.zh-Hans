# 编辑或添加图像

![](../assets/16_hierarchy_of_controls_eliminate_substitute_updated.png)

选择任意图像以打开图像工具栏。 控制包括：

- **填充**，**适合：**&#x200B;图像在帧内的大小调整方式

- **替换文本**&#x200B;字段：显示图像描述。<br>
  **注意**：此文本无法修改。 它会根据图像自动更新。

- **更多选项**&#x200B;图标： **调整**&#x200B;图像的亮度、饱和度和透明度。

要替换图像，请选择&#x200B;**图像**&#x200B;图标以更改图像。 选择上传您自己的文件、搜索Adobe Stock或使用AI生成文件。
