# 编辑课程大纲

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager Content Composer会根据您的摘要和源文件生成课程和主题结构。 此时画布上会显示大纲，显示所有课程及其主题。

**注意：**&#x200B;大纲编辑当前在Beta版中是对话式的。 无法在画布上选择课程或主题进行重命名或重新排序。 在聊天面板中将您的更改键入为纯语言请求。

助手说话说话。 您可以用您自己的语言表述请求。 以下是您可以执行的一些操作示例：

| **操作** | **示例请求** |
|--------------------------|---------------------------------------------------------------------------|
| 重命名课程或主题 | “将第1课重命名为‘网络钓鱼的运作方式’” |
| 添加课程或主题 | “在第2课中添加有关QR码钓鱼的主题” |
| 删除课程或主题 | “删除主题1.3” |
| 拆分课程 | “把第三课拆成两课。 一个用于垃圾邮件过滤器，一个用于修补程序管理” |
| 合并课程 | “将第3节和第4节课合而为一” |
| 重新生成轮廓 | “以密码卫生为重点进行再生” |

在聊天面板中使用纯语言请求修改课程、主题或完整的大纲结构。

大纲层次结构已固定为“课程”>“主题”。 不能创建子主题或三层结构。

当大纲显示正确时，选择顶部工具栏中的&#x200B;**生成课程**。
