# 编辑课程文本

![](../assets/15_lesson_image_text_block_fall_prevention_updated.png)

选择任意文本元素以将光标置于其中。 画布底部会显示一个格式工具栏，其中包含粗体、斜体、下划线、删除线、链接、对齐和列表控件。

>[!NOTE]
>
>主题名称和课程名称是大纲结构的一部分。 要在生成课程后重命名它们，请助理操作：“将第2课重命名为‘密码安全’”。 不能通过在课程编辑器中选择一个标题来重命名它们。
