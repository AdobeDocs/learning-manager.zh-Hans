# 导出主题

将主题导出为JSON 文件，以便在Content Composer之外自定义主题或与其他作者共享。

1. 从工具栏中选择&#x200B;**主题**&#x200B;以打开&#x200B;**课程主题**&#x200B;面板。

2. 将鼠标悬停在要导出的主题上，然后选择&#x200B;**导出**图标。
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. 在出现的对话框中，选择一个位置，输入&#x200B;**文件名。**
