# 内容书写器工作原理

内容书写器处理创作。 Adobe Learning Manager可处理交付、注册、跟踪和报告。 了解此拆分说明为什么发布到ALM不需要手动重传SCORM即可导出到第三方LMS。

| **内容书写器控件** | **Adobe Learning Manager控件** |
|-------------------------------------------------------------------------|----------------------------------------------------------|
| 课程和主题结构 | 学习者注册和访问 |
| 课程内容 — 文本、图像、视频、组件和知识检查 | 模块元数据 — 持续时间、标签、唯一ID和到期时间 |
| 课程结束测验，包括问题类型和答案 | 课程组合和版本控制 |
| 视觉主题、完成标准和成功标准 | 学习者跟踪、报告和成绩单 |

Adobe Learning Manager Content Composer按以下顺序经历了四个阶段：

- **主屏幕：**&#x200B;编写提示，以简单语言描述课程。 AI会读取您的提示并预先填写课程摘要。

- **简介：**&#x200B;您确认以下字段：

  - 课程标题

  - 学习者配置文件

  - 学习目标

在此阶段中，可上传要从中绘制的AI的文件，并选择是否将生成的内容限制为仅包含这些文件。 这些输入塑造了AI在下游生成的所有内容。

- **大纲：** AI会以其目标结构提出课程和主题。 您可以通过聊天面板查看它并请求更改。

当大纲正确时，即生成整个课程。

- **课程：** AI会生成完整的课程，并分为三个级别：

  - **课程：**&#x200B;课程的主要部分，每个部分都涵盖主题的不同部分

  - **主题：**&#x200B;每节课中的各个单元，每个单元都侧重于单个概念或技能

  - **块：**&#x200B;构成每个主题的内容元素：文本、图像、视频、交互组件（如翻转卡、折叠图和时间轴）以及内嵌知识检查

每个课程末尾都会添加一个评分测验。

**注意**：课程和主题结构来自您在上一阶段批准的大纲。

您可以在共享或发布之前审阅、编辑和优化所有内容、测验和视觉主题。

**试用。**

试用&#x200B;[**Content Composer**](https://contentcomposer.adobe.io/)并描述要生成的课程。

对话助理贯穿全部四个阶段。 它应要求进行更改，提出替代方案，并解释它可以做什么，不能做什么。
