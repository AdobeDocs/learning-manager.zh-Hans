# 管理和回复注释

如果您是作者，则可以使用项目中的&#x200B;**评论**&#x200B;面板查看和回复评论。

1. 从顶部工具栏中选择&#x200B;**注释**。 **注释**&#x200B;面板将打开，显示所有审阅者注释。

   ![](../assets/63_owner_in_app_comments_panel_mention_comment.png)

2. 选择任意注释以在画布的上下文中查看它。

   ![](../assets/64_comment_in_context_on_canvas.png)

3. 选择复选标记图标将评论标记为已解决，或选择&#x200B;**更多选项**&#x200B;图标进行编辑或删除。

   ![](../assets/65_comment_resolve_checkmark_delete_menu.png)

4. 保存更新后的课程。

5. 选择“**共享**”以更新审阅链接，这样审阅者就可以查看最新版本。
