# 查看和编辑测验

![](../assets/12_quiz_block_question_view_updated.png)

一个评分测验会出现在课程末尾。 每个问题都标记有它所测试的主题。

>[!NOTE]
>
>课程中的知识检查没有评分。 仅对课程结束测验进行评分。


编辑问题：

1. 选择要编辑的问题文本，然后使用文本编辑选项调整样式。
   ![](../assets/13_quiz_question_text_edit_toolbar_updated.png)

2. 选择要标记为正确的选项旁边的单选按钮。

3. 您也可以为正确答案指定分数。
   ![](../assets/14_quiz_question_options_scoring_panel_updated.png)

4. 若要删除问题，请选择&#x200B;**删除选项**。

5. 要重新生成问题，请咨询助手：“重新生成第1课的测验。”
