# 查看共享的课程

在共享项目以供审阅时，您可以向与您共享的链接添加注释。

1. 打开与您共享的审阅链接。

2. 在右侧的&#x200B;**评论**&#x200B;面板中，添加您的评论并选择&#x200B;**提交**。

可在&#x200B;**注释**&#x200B;面板中执行以下操作：

* 添加、编辑、删除、回复和解决评论。
* 查看其他审阅人的注释。
* 使用&#x200B;**@**&#x200B;提及项目所有者或其他审阅者（仅当您使用Adobe ID登录时）。
* 在您的评论中添加表情符号。
* 按&#x200B;**审阅人**、**时间**&#x200B;和&#x200B;**已解决**&#x200B;状态筛选评论。
