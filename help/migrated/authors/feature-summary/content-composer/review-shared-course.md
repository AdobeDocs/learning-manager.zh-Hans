# 审阅和评论共享项目

共享项目以供审阅后，您可以作为审阅者通过作者共享的链接访问课程。

1. 打开与您共享的审阅链接。

2. 在右侧的&#x200B;**注释**&#x200B;面板中，选择任何需要更改的课程组件。 组件名称显示在注释字段的顶部，因此您的反馈会始终链接到课程的右侧。 在下方添加您的评论。

   ![](../assets/60_comments_panel_add_comment_existing_thread.png)

   在&#x200B;**注释**&#x200B;面板中，您可以：
   * 添加、编辑、删除、回复和解决评论。
   * 查看其他审阅人的注释。
   * 使用&#x200B;**@**&#x200B;提及项目所有者或其他审阅者（仅当您使用Adobe ID登录时）。
   * 在您的评论中添加表情符号。
   * 查看课程中的所有注释：默认情况下，“注释”面板仅显示您当前查看的课程组件的注释。 打开所有屏幕注释切换按钮即可查看整个项目中的每条注释，而无需考虑您处于哪个组件或屏幕上。

   ![](../assets/61_all_screen_comments_toggle.png)

   * 按&#x200B;**审阅人**、**时间**&#x200B;和&#x200B;**已解决**&#x200B;状态筛选评论。

   ![](../assets/62_comments_filter_reviewers_time_status.png)

3. 选择&#x200B;**提交**&#x200B;以发布您的注释，或选择&#x200B;**取消**&#x200B;以放弃该注释。

## 举报冒犯性内容

如果您在查看共享内容书写器课程时遇到了违反Adobe[使用条款](https://www.adobe.com/legal/terms.html)的内容，您可以报告此情况。

从右上角选择&#x200B;**报告**&#x200B;并填写表单。 或者，您可以通过电子邮件向[abuse@adobe.com](mailto:abuse@adobe.com)举报滥用情况。
