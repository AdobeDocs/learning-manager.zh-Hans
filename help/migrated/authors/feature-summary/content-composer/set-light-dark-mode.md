# 为课程设置浅色模式或深色模式

<!--Select **light/dark** mode in the toolbar to toggle between modes. Content Composer updates the canvas to reflect the selected mode.-->

选择“[!UICONTROL 帐户”菜单] > [!UICONTROL 应用主题] >浅色或深色模式。 内容书写器会更新画布以反映所选模式。
