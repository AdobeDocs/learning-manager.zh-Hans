# 查看课程并添加评论

如果您是课程创建者，请选择项目中的&#x200B;**评论**&#x200B;面板以查看评论并回复它们。

1. **打开注释面板**：从工具栏中选择&#x200B;**注释**。 注释面板显示审阅者提供的注释。

2. 您可以将注释标记为“已解决”，或者编辑或删除注释。

3. 进行所需的更改并&#x200B;**保存**&#x200B;项目。

4. 从工具栏中选择&#x200B;**共享**&#x200B;以更新最新链接。
