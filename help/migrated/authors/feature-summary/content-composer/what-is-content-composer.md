# 什么是Adobe Learning Manager Content Composer

Adobe Learning Manager Content Composer将课程创建的每个阶段组合成一个AI指导的工作流程。 您可以描述想要教授的内容，产品会根据您的输入生成结构化的大纲和完整的课程内容，包括图像、知识检查和分级测验。

Content Composer将学习创作的所有阶段都整合到一个工作流程中，并支持使用能够理解教学设计的AI进行共同创作，从而帮助您创建不仅制作速度更快，而且设计效率更高的学习。

课程准备就绪后，您可以：

- 直接从Publish课程发送至Adobe Learning Manager，并通过全面的学习者分析深入了解学习效果。
- 将其作为SCORM包下载，以便在任何兼容的LMS中使用。
