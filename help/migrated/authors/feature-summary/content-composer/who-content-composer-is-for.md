# Adobe Learning Manager内容书写器面向何人

Adobe Learning Manager Content Composer专为那些需要在不从头开始的情况下创建结构化课程的人而设计。

| **角色** | **内容书写器如何帮助** |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **作者** | 创建结构化、有效的课程。 您既可以将自己的知识转换为课程，使用现有文档和源材料，也可以优化AI生成的内容以满足特定学习目标。 |
| **L&amp;D管理员** | 设置访问权限、设置组织主题并将已完成的课程发布到Adobe Learning Manager。 |
| **L&amp;D管理器** | 在课程分发给学习者之前，请先审阅并批准课程。 |
