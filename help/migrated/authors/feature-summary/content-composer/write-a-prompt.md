# 编写提示

![在内容书写器主屏幕上编写提示](../assets/1_coco_home_landing_screen_updated.png)

在Content Composer主屏幕上，键入您想要创建的课程的说明。 用简单的语言写作 — 一两句话，命名主题、受众和目标。

**示例提示：**

- 我想创建一门关于IT安全意识的课程，包括网络钓鱼模拟、密码安全保护和其他保护方法。

- 我想为新客户支持客服专员创建一个入门模块，介绍如何在我们的“服务台”系统中记录票证、升级问题和关闭案例。

- 我想为仓库工作人员开设一门复习课程，介绍手动搬运过程，例如正确的抬举技巧、何时使用设备以及如何报告差点失误。

选择&#x200B;**开始使用**。 内容撰写器会打开&#x200B;**摘要**&#x200B;阶段，并读取您的提示以开始填写课程详细信息。

**提示**：提示无需完美。 助理会在每个步骤询问跟进问题，以便在生成任何内容之前细化职务、学习者配置文件和目标。

## 编写有效提示

在Content Composer中编写可生成准确的课程摘要、更好的轮廓和更强大的AI生成内容的提示。

提示是您向内容书写器提供的第一个输入，也是最重要的输入。 清晰、具体的提示意味着AI可以更准确地预填摘要，生成符合您意图的轮廓，并生成需要较少编辑的课程内容。

### 是什么让一个提示有效？

Content Composer会读取您的提示并使用它预填三个简短字段：课程标题、学习者配置文件和学习目标。 你的提示越是反映这三个维度，这份简报所需的修正就越少，而一个更准确的简报就会产生一个更相关的轮廓。

标有“创建安全课程”的提示几乎不会为AI提供任何处理功能。 给受众命名、指定主题并指示范围的AI提示足以生成您只需进行最少的更改即可接受的简短。

简短的字段还会放大提示中的内容。 如果提示含糊不清，AI会生成一个模糊的摘要。 一个模糊的简要说明生成一个泛型大纲。

有关详细信息，请参阅[编写有效提示](write-effective-prompts.md)。
