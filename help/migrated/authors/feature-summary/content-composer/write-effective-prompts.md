# 编写有效提示

在Content Composer中编写可生成准确的课程摘要、更好的轮廓和更强大的AI生成内容的提示。

提示是您向内容书写器提供的第一个输入，也是最重要的输入。 清晰、具体的提示意味着AI可以更准确地预填摘要，生成符合您意图的轮廓，并生成需要较少编辑的课程内容。

## 是什么让一个提示有效？

Content Composer会读取您的提示并使用它预填三个简短字段：课程标题、学习者配置文件和学习目标。 你的提示越是反映这三个维度，这份简报所需的修正就越少，而一个更准确的简报就会产生一个更相关的轮廓。

标有“创建安全课程”的提示几乎不会为AI提供任何处理功能。 给受众命名、指定主题并指示范围的AI提示足以生成您只需进行最少的更改即可接受的简短。

简短的字段还会放大提示中的内容。 如果提示含糊不清，AI会生成一个模糊的摘要。 一个模糊的简要说明生成一个泛型大纲。

## 构造强提醒

一个有力的提示回答了三个问题，一两句是：

- **哪些人**&#x200B;是学习者？ 命名他们的角色和体验级别。

- 课程涵盖&#x200B;**什么**？ 命名2-3特定主题，而不是宽泛的主题领域。

- **您想要什么范围或结果**？ 信号持续时间、深度或学习者能够执行的操作。

## 有效提示的剖析

**[受众+体验级别]** + **[2-3个特定主题]** + **[范围或结果信号]**

**示例**：

我想为新销售代表创建一门课程，内容涵盖我们的企业定价层、折扣审批工作流程，以及如何处理最常见的三个客户异议。

分解为：

- **受众：**&#x200B;位新的销售代表

- **主题：**&#x200B;企业定价层、折扣审批流程、三个常见异议

选择“**开始使用**”后，内容编辑器将打开“**简介**”阶段。 在生成大纲之前，查看AI根据提示生成的预填充字段、标题、学习者配置文件和目标，并优化任何与您的意图不匹配的内容。

## 有或没有有效的提示

| **包含** | **避免** |
|--------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| 特定受众角色（“新销售代表”、“一线经理”） | 含糊的受众（“所有员工”、“所有人”、“用户”） |
| 2-3个具体专题领域 | 一个提示中包含超过6个主题 — 这会导致大纲过载；应将其拆分为单独的课程 |
| 范围信号 — 持续时间、深度或学习者结果 | 一般目标（“向他们传授X的一切”，“涵盖所有方面”） |
| 形成色调或深度的上下文（“用于合规性”、“用于非技术受众”、“基于情景”） | 询问AI问题。 提示是简短的，而不是对话 |
| 学习者在课程结束后可以执行的操作 | 课程将包含的内容（将结构保留到大纲阶段） |

## 提示太模糊时会发生什么？

如果提示范围很广，则AI会生成大致的摘要，从而生成一般轮廓。 课程大纲可能涵盖正确的主题领域，但缺乏课程需要的特定结构。 您将花费更多的时间通过对话编辑轮廓，而不是编写更好的提示。

提示过于模糊的最常见迹象是：

- 摘要的学习者资料是通用的（“想了解X的员工”），而不是特定于某个角色

- 大纲包含适用于任何主题课程（“简介”、“关键概念”、“摘要”）的课程标题

- 该目标没有提到可衡量的行为。 相反，它会描述课程主题

## 最佳实践

- 在打开内容编辑器之前编写提示。 预先拟定的句子在输入域的压力下往往比键入的句子更清晰。

- 按角色而不是按大小命名受众。 “新销售代表”比“一大群员工”更有用。

- 将提示限制为2-3个主题。 更多主题会产生过载的大纲。 如果您的主题需要三节以上课程，请创建单独的课程。

- 首先要处理提示。 简短字段是可编辑的。 如果AI的建议是接近但不正确，请直接细化字段，而不是从头开始重写提示。
