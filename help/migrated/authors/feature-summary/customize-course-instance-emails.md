# 在电子邮件生成器中自定义课程和实例电子邮件

作者可以为课程或课程的特定实例自定义电子邮件。 这两个过程都从管理员提供的布局开始。

## 自定义课程级电子邮件

1. 打开课程。
2. 选择&#x200B;**电子邮件模板**。
3. 选择&#x200B;**课程电子邮件布局**。
4. 自定义电子邮件内容。 设置字体、颜色、行和按钮。
5. 保存模板。
6. Publish课程。

## 自定义实例级电子邮件

当不同群组需要不同的消息时，请使用实例级电子邮件。 您可以通过课程实例管理这些同类群组。

1. 打开课程实例。
2. 打开&#x200B;**电子邮件生成器**。
3. 选择一个可用布局，或继承实例已使用的布局。
4. 更新消息内容。
5. 保存模板。

>[!NOTE]
>
>如果同时存在这两个模板，实例级别电子邮件将覆盖课程级别模板。

## 使用“标题”变量和电子邮件标头的图像

结合使用Title变量和Image组件构建电子邮件标头，而不是Banner组件。 在某些电子邮件客户端（如Outlook）中不会显示Banner组件的图像。

标题变量EmailTitle的作用类似于现有的ChannelName变量。 每个电子邮件都有自己的默认标题值。

要添加标题标题，请执行以下操作：

1. 为标题图像添加图像组件。
2. 添加文本组件，并从组件配置窗格中的变量下拉列表中插入标题变量。
3. 居中对齐文本组件。 在全局布局中，将其放在顶部页眉中。

   默认情况下，单个电子邮件使用全局布局中的标题。 在单个电子邮件中，您可以编辑文本组件以便：

4. 将变量替换为自定义文本
5. 在变量之前或之后添加文本并保留`EmailTitle`

如果将图像添加到横幅组件，电子邮件生成器会显示一条警告，提示图像在某些电子邮件客户端中可能无法正确显示。 此警告建议改用Image组件和title变量。

## 故障排除

**无法选择布局。**
版面继承取决于可用的主页版面。 请求管理员创建帐户布局。

**您的电子邮件未显示最近的布局更改。**
模板可能会与其版面取消链接。 未链接的模板不再接收布局更新。

**实例中的学习者收到的电子邮件与课程电子邮件不同。**
实例级电子邮件会覆盖课程级模板。 查看实例级模板。

**您的课程或实例电子邮件中看不到Email Builder。**
Adobe会分阶段启用电子邮件构建器。 让管理员确认您的帐户已启用电子邮件生成器。

**您的横幅图像未出现在电子邮件中。**
某些电子邮件客户端（如Outlook）不显示横幅组件的图像。 删除横幅组件，添加图像组件，并添加使用标题变量的文本组件。
