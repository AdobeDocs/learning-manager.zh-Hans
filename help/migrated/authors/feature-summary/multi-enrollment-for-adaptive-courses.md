# 自适应课程的多重注册

## 概述

多注册允许学习者同时注册同一课程的多个实例。 在Adobe Learning Manager中，您现在可以启用自适应课程的多重注册。

## 关于自适应课程的多重注册

自适应课程仅显示与其用户组匹配的模块。 开启多注册后，学习者可以参加该课程的多个实例，例如不同月份的课程。

自适应课程会在模块级别而不是实例级别跟踪轮候表。 学习者可能正在学习某些模块，并同时在其他模块中轮候。 例如，课程有两个实例，每个实例的名额限制为1。 第一个学习者会在两个实例中注册并占据两个席位。 在两个实例中注册的第二个学习者将在两个实例中轮候。

## 为自适应课程启用多注册

1. 以作者身份登录Adobe Learning Manager 。
2. 在左侧导航栏中选择&#x200B;**课程**。 打开或创建自适应课程。
3. 添加模块。 对于每个内容模块，选择&#x200B;**添加规则**&#x200B;以设置可以查看该模块的用户组和必须查看该模块的用户组。
4. 选择&#x200B;**“保存”**。 多注册选项变为可用。
5. 打开&#x200B;**多注册**&#x200B;切换。
6. 创建所需的实例。 对于教室和虚拟教室会话，请设置名额限制。
7. 选择&#x200B;**Publish**。

学习者现在可以注册多个课程实例。

## 名额限制和轮候表行为

自适应课程会对每个教室或虚拟教室会话实施名额限制。 学习者会立即注册，并且仅在已满会话中处于轮候状态。 学习者可以立即开始学习所有其他模块。

| 条件 | 结果 |
|------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| 所有可见的答疑都有可用名额 | 学习者可在注册后获得所有模块的完全访问权限。 |
| 一个或多个可见会话已满 | 学习者仅会在整个会话中注册并轮候。 |
| 您将无名额的必修会话添加到包含已注册学习者的课程中 | 学习者在新会话中列入轮候表。 现有进度和访问不受影响。 |
| 用户组更改会从学习者的可见模块中删除会话 | Adobe Learning Manager立即释放了席位。 |
| 学习者切换到其他实例 | 已完成的模块将保持完成状态。 名额仅用于学习者尚未完成的可见模块。 |

## 自适应学习路径的注册和完成规则

作者现在可以在Adobe Learning Manager中将自适应课程添加到自适应学习路径中。 注册、轮候和完成操作均遵循章节设置和作者配置的课程设置相结合的规则。

### 自适应学习路径如何评估学习者

Adobe Learning Manager会在章节级别和课程级别评估可见性。 章节规则决定学习者是否看到章节及其中的自适应课程。 然后根据每个自适应课程中的模块规则确定学习者是否已注册该课程。

只要自适应学习计划内自适应课程有UG变更，学习者将自动注册。 学习者也会收到自动注册通知和电子邮件。

### 注册评估规则

在为学习者注册自适应学习路径时，Adobe Learning Manager会按以下顺序检查路径：

| 订购 | 检查 | 结果 |
|-----------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | 章节可见性 | 仅当课程部分对学习者可见时，Adobe Learning Manager才会检查课程是否注册。 |
| 2 | 课程资格 | 如果课程没有学习者的必修模块，则学习者不会注册该课程。 该课程不计入学习路径完成。 |
| 3 | 无合格课程的章节 | 如果某个章节仅包含自适应课程，而学习者没有资格参加任何自适应课程，则Adobe Learning Manager会跳过此章节。 |
| 4 | 学习路径注册 | 如果任何必修部分都不适用于学习者，则学习者不会注册学习路径。 |

如果学习者已注册属于该学习路径实例的课程实例，则Adobe Learning Manager会使用该注册。

注册后，适用以下规则：

* 如果日后因为可见性/强制性规则更改而显示适应性课程，则最初由于可见性而跳过了课程的学习者可以自动注册。
* 用户组更改或课程更改可能会将学习者取消注册自适应课程。 如果路径中不再保留任何强制性内容，则学习者将无法注册该路径。
* 对于章节更改，学习者不会收到任何自动注册通知或电子邮件。 只需重新加载页面，学习者即可看到更改。

### 自适应学习路径中的轮候表行为

轮候表将在会话级别而不是实例级别进行。 这同样适用于学习路径中的自适应课程。

| 情景 | 行为 |
|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| 路径中没有具有教室或虚拟教室模块的自适应课程 | 轮候表不适用。 |
| 自适应课程具有教室或虚拟教室模块，但未选择实例 | 课程默认为&#x200B;**无实例**。 学习者可以注册任何实例，并且仅在已满会话中轮候。 |
| 注册前已选择实例 | 学习者已注册该实例，并且仅在会话已满时轮候。 |

要管理轮候学习者，请打开自适应课程，然后选择&#x200B;**学习者** > **轮候表**&#x200B;选项卡。 对于弹性学习路径和自适应学习路径中的自适应课程，轮候学习者仅显示在课程的&#x200B;**轮候表**&#x200B;选项卡上，而不显示在学习路径下。

### 刷新完成和回滚行为

Adobe Learning Manager不会在用户组或规则更改时自动撤销完成请求。 在您刷新完成之前，已完成学习者将保持完成状态。

* 对学习路径运行&#x200B;**刷新完成**。 您无法单独刷新路径学习者的自适应课程。

* 首先根据学习者当前的必修模块重新计算每个自适应课程。 然后，学习路径会根据当前必修部分和重新刷新的课程状态重新计算。

* 如果课程或路径不再完成，学习者的状态会更改为“进行中”。 最初的完成情况将作为历史记录保留在学习者成绩单中。

* 完成回滚会查找其模块因用户组更改或重新发布而发生更改的自适应课程。 它会重新计算这些课程，然后计算学习路径。 回滚完成时，作业状态显示&#x200B;**成功**。

轮候表将在模块级别进行跟踪。 学习者可以在多个实例的完整会话中轮候。 例如，课程有两个实例，每个实例的名额限制为一个。 第一个学习者会在两个实例中注册并占据两个席位。 在两个实例中注册的第二个学习者出现在每个实例的&#x200B;**轮候表**&#x200B;选项卡上。

### 为轮候学习者分配名额

当学习者取消注册、作者增加名额限制或学习者切换实例时，Adobe Learning Manager会按注册日期顺序清除轮候表。 您还可以手动分配席位。

1. 打开自适应课程。
2. 选择“**学习者**”>“**轮候表**”选项卡。
3. 选中您要为其分配名额的每个学习者旁边的复选框。
4. 选择&#x200B;**分配席位**。

Adobe Learning Manager会一次清除所有轮候会话中轮候表中的每个选定学习者，而不仅仅是您正在查看的会话。 系统假设您已经为学习者安排了席位。
