# 使用虚拟指导模板创建角色扮演

Publish是一种预建的虚拟教练场景，它从模板开始，而不是从头开始构建角色扮演。

Virtual Coach的&#x200B;**精选**&#x200B;和&#x200B;**可用模板**&#x200B;部分包含一个预建的角色扮演情景库，涵盖销售、领导力和技能评估情况。 使用模板是创建角色扮演的最快方式 — 已配置角色、打开对话、主题和得分，您可以立即发布或在发布之前自定义任何详细信息。

模板按域、模拟类型和语言进行组织。 使用筛选器按交互类型（例如&#x200B;**语音对话**&#x200B;或&#x200B;**网络摄像头练习**）缩小列表范围，或按关键字搜索以查找与您的用例最接近的场景。

>[!TIP]
>
>选择模板不会将您锁定在其默认配置中。 选择模板后，可以编辑每个字段，包括角色背景、主题、分数权重和对话打开。 将模板视为起点，而非最终设计。 有关每个可配置字段的完整说明，请参阅[创建并发布虚拟指导角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)。


1. 以作者身份登录Adobe Learning Manager 。
2. 在左侧导航窗格中选择&#x200B;**虚拟教练**。
3. 选择&#x200B;**立即创建**。
4. 浏览&#x200B;**可用模板**&#x200B;部分，或使用&#x200B;**搜索**&#x200B;栏和域、模拟类型和语言筛选器查找与您的方案匹配的模板。

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. 选择模板磁贴以将其打开。 查看角色、主题和评分配置。

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *在决定是否自定义模板之前，请查看预填充的对话上下文和角色背景。*

6. 若要按现状使用模板，请选择&#x200B;**Publish**。 要首先自定义它，请选择任意部分并编辑相关字段，然后再发布。

发布后，角色扮演将添加到&#x200B;**内容库**&#x200B;中，随时可以添加到工作辅助并分配给课程。 请参阅[在课程中添加虚拟教练角色扮演](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md)以了解这些步骤，或[练习使用虚拟教练进行角色扮演](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md)以查看学习者体验。
