# 设计角色扮演

## 简介

虚拟教练是一项Adobe Learning Manager功能，可让学习者使用AI支持的角色练习逼真的职场对话，并接收个性化的指导反馈。 与传统评估知识召回率的做法不同，虚拟教练会评估学习者在模拟的现实环境中运用知识、沟通技巧、解决问题的技能和决策的有效性。

角色扮演的质量直接影响学习者的体验。 精心设计的角色扮演会让人感觉真实，挑战学习者的批判性思维，呈现现实障碍，并衡量有意义的行为。 设计不当的角色扮演往往感觉像是照本宣科、笼统以及与职场现实脱节。

本指南提供了用于设计有影响力的角色扮演的框架、用于创作的最佳实践、可立即改编的示例库，以及从每个设计概念到您将在虚拟教程中配置的实际字段的映射。

## 本指南面向哪些用户

本指南适用于在打开“编辑”屏幕之前计划进行“虚拟教练”角色扮演的课程作者和教学设计师。 它还适用于审阅或批准角色扮演内容的L&amp;D利益相关者，因为Gold Standard模板和发布前核对清单同时用作审阅指标。

本指南将范围界定为对话设计：情景、角色、目标和评估标准，用于确定角色扮演是否真实并衡量正确的事。

## 了解角色扮演的剖析

每一次成功的角色扮演都建立在四个基本要素之上：

1. 情景
2. 角色
3. 对话目标
4. 评估标准

这些元素共同确定了学习者体验的质量和指导反馈的价值。

### 情景：为什么会出现这种对话？

该方案建立业务环境。 它解释道：

* 参与者参加会议的原因
* 什么业务事件引发了讨论
* 对话之前发生的事情
* 利害关系
* 为什么讨论很重要

如果没有强有力的情景，AI会引发对话，但可能缺乏深度、现实和紧迫性。

**要询问的问题**

在编写场景之前，请回答以下问题：

* 这些人为什么在说话？
* 什么事触发了这次谈话？
* 这是第一次互动还是后续活动？
* 正在讨论什么业务问题？
* 如果对话不成功会发生什么？

**示例**

**弱方案。** 客户希望了解Adobe Learning Manager。

**强方案。** Director在参加员工技能提升网络研讨会后，同意发起探索性电话会议。 该组织当前的LMS合同将在9个月后到期，领导层已指示L&amp;D团队在提交预算申请之前评估替代解决方案。

第二个示例提供了环境、紧迫性、决策相关性和现实业务驱动因素。

**最佳实践**

定义关系阶段。 指定参加培训者的培训路线 — 例如：首次发现呼叫、产品评估会议、执行官业务回顾、续订谈判、升级讨论、领导力培训课程或性能反馈会议。

包括触发事件 — 例如：LMS替换计划、审核失败、采用率下降、产品中断、组织重组、收入目标缺失或战略人工智能推广。

带来后果。 良好角色应包括风险 — 例如：预算损失、法规遵从性失败、客户流失、员工离职、延迟实施或管理层审查。

### 角色：与谁说话的学习者？

人物能营造出真实感。 角色应该感觉像真正的利益相关者，而不是虚构的角色。 有效的角色包括：角色、责任、目标、优先事项、关切、压力、沟通风格和个性。

**要询问的问题**

* 他们应该对哪些结果负责？
* 什么担忧会影响他们的决定？
* 他们通常如何沟通？
* 他们可能会提出哪些反对意见？

**示例**

**弱角色。** 对LMS平台感兴趣的Learning Manager。

**强角色：**

* 角色：学习和人才发展副总裁
* 人格：分析和怀疑
* 当前职责：监督20,000名员工的学习计划；向主管领导报告学习效果指标；管理LMS现代化计划
* 目前的压力：预算削减；六个月内的合规审计；行政部门的要求改善报告
* 主要问题：迁移复杂性；用户采用；成本论证；执行赞助

**最佳实践**

给予角色以顾虑。 大多数角色应该有3到5个问题。 这些担忧自然成为反对和挑战性对话的根源。

添加情绪情境。 人们很少在情绪上中立的对话 — 例如：沮丧、怀疑、紧张、防御、好奇或乐观。

定义沟通风格 — 例如：直接、分析、面向关系、保留、自信或具有挑战性。

### 对话目标：学习者应完成哪些工作？

目标定义了成功。 最常见的错误之一是关注话题而不是结果。

**较差的目标。** 讨论入门培训。

**更好的目标。** 确定入门挑战，并获得执行官同意启动试点计划。

**最佳实践**

关注结果 — 例如：确保后续会议、解决投诉、获得利益相关者的支持、获得管理层的批准、制定绩效改进计划或为试点项目赢得协议。

定义可衡量的成功。 在对话结束时，应明确学习者是否成功了。

### 评估标准：如何衡量成功？

评估标准定义了AI应评估的内容。 最有效的标准侧重于可观察的行为。

**评估标准良好**

* 开放式问题解答
* 已确认的理解
* 问题摘要
* 探索业务影响
* 解决异议
* 已确定的后续步骤

**评估标准不佳**

* 听起来很有信心
* 看起来很专业
* 很有说服力
* 展示领导力

这些评价是主观的，难以进行一致评价。

**最佳实践**

评估行为，而不是人格特质。 问：“对话记录中应显示哪些具体操作？” 如果可以听到或观察到这种行为，它可能是很好的评价标准。

限制评估类别。 大多数角色扮演在三到六个评估领域、清晰描述和可衡量的行为方面表现最佳。

## 设计逼真的对话

### 引入张力

最佳角色扮演包括障碍。

| **函数** | **张力示例** |
|---|---|
| 销售 | 潜在客户对ROI提出疑问。 |
| 客户成功 | 客户认为，采用问题不再成为首要问题。 |
| 领导力 | 员工不同意反馈意见。 |
| 变更管理 | 利益相关者担心失去对决策的控制权。 |

没有紧张关系，对话往往变得过于容易和不现实。

### 设计相互竞争的优先级

真正的利益相关者很少关注单一问题。 Learning的VP可能同时关心成本、法规遵从性、用户采用、实施时间表和执行报告。 相互竞争的优先任务可创造更丰富的对话和更好的培训机会。

### 建立对话，而不是面谈

虚拟教练应该模拟真实的对话，而不是问题清单。 应鼓励学习者探索、澄清、指导、谈判、影响和解决问题。

## 角色扮演成熟度模型

角色一般通过五个成熟度级别取得进展，从一般的单问题交流到完全适应的、多方利益攸关方的模拟。 使用此模型可规划角色扮演应如何随着学习者从入门到熟练的转变而发展，而不是在第一次尝试时尝试创作5级复杂性。

### 第1级：基本角色扮演 {#level-1-basic-role-play}

**方案。** 与潜在客户进行发现呼叫。

**角色。** 潜在客户。

**目标。** 了解要求。

**评估标准**

* 提出问题
* 了解需求
* 推荐解决方案

*此级别启用AI交互，但通常感觉较一般。*

### 第2级：上下文驱动的角色扮演 {#level-2-context-driven-role-play}

**方案。** 潜在客户参加了网络研讨会，并请求了调查电话。

**角色。** Learning Manager评估培训解决方案。

**目标。** 了解培训挑战。

**评估标准**

* 发现
* 问题识别
* 摘要
* 下一步对齐方式

### 第3级：以业务为重点的角色扮演 {#level-3-business-focused-role-play}

**方案。** 由于合同即将到期，组织计划替换其LMS。

**角色。** Director学习督导平台现代化。

**目标。** 了解业务需求并保障演示。

**评估标准**

* 发现效率
* 利益相关者映射
* 痛点识别
* 异议处理

### 第4级：多方利益攸关者发挥的作用 {#level-4-multi-stakeholder-role-play}

**方案。** 数字学习转型计划需要获得金融、IT和商业赞助方的同意才能继续实施，每个利益相关方都有不同的优先级。

**角色。** 一个会议中有三个角色，每个角色都具有独特的角色、个性和顾虑（例如，一位首席财务官专注于成本，一位IT Director专注于安全，一位业务赞助商专注于时间表） — 配置为多角色扮演，最多可有四个角色。

**目标。** 在同一对话中为每个利益相关者调整信息，并确保他们之间保持一致，而不仅仅是那些声音最响亮的对话者。

**评估标准**

* 各利害关系方的报文适应
* 个人异议处理（按角色）
* 跨相互竞争的优先任务进行综合和协调
* 每个利益相关者的下一步承诺

*本指南后面部分介绍的“执行领导”示例的复杂性。 大多数学习者在尝试级别4之前应掌握级别3。*

### 第5级：适应性强、风险高的角色扮演 {#level-5-adaptive-high-stakes-role-play}

**方案。** 一项战略计划已经落后于预定计划，而且预算超支，如果学习者在对话的初期没有解决他们最关心的问题，那么人物的耐心和怀疑就会明显增加。

**角色。** 在对话的中间，资深利益相关者的语气和阻力会根据学习者的表现来调整 — 例如，一旦特定的问题解决后，他们会变得更加合作，或者如果反对意见被转移而不是得到解决，他们会更加怀疑。

**目标。** 尽管一开始处于敌对状态，但仍恢复利益相关者的信心和可靠的承诺。

**评估标准**

* 自适应异议处理
* 在压力下减少升级
* 从破败的开盘中复苏
* 管理层谈判和结语

*这是最高复杂度的等级：它依赖于配置有高度顾虑时机的人物（“当出现时”），因此AI的色调会根据学习者的说法真正变化，而不是遵循固定的脚本。 保留此级别用于资本评估，而不是早期实践。*

## 企业方案库

下面的销售支持示例是此库已全面投入使用的参考 — 填写了Gold Standard Template调用的每个字段，包括加权评估标准、成败标志、开场白和异议。 其余示例采用相同的结构，因此它们同样可以适应；没有故意缩写。

### 销售支持：企业LMS评估

**方案。** 一家拥有超过40,000名员工的全球制造组织正在评估LMS供应商，因为其当前的平台合同将在9个月内到期。 学员是一名客户经理，在行业会议上与潜在客户进行了首次正式的发现对话。 本组织在25个国家开展业务，目前使用五个互不相连的学习系统。

**角色**

| **字段** | **详细信息** |
|---|---|
| 姓名 | Sarah Thompson |
| 角色 | 学习和人才发展副总裁 |
| 系统个性 | 持怀疑态度 |
| 沟通风格（背景细微差别） | 分析性和直接性；在信任索赔之前需要证据。 |
| 优先级 | 整合学习系统；改进合规性报告；减少管理开销；增加学习者采用率 |
| 压力 | 合规性审核计划在6个月内进行；执行机构现代化计划；之前的迁移超出预算 |

**人物志问题**

* 迁移复杂性 — 在学习者描述实施时间表时出现。 做得好：学习者概述了分阶段的迁移方法，并注明了里程碑。
* 用户采用 — 在学习者讨论推广时出现。 做得好：学习者参考了最终用户的更改管理或培训计划。
* 高管赞助 — 在谈话接近尾声时出现。 足够好：学习者确定其他哪些人需要参与决策。
* 隐藏的实施成本 — 在讨论定价时会出现。 足够好：学习者可以主动解决总拥有成本，而不仅仅是许可价格问题。

**目标。** 学习者必须发现业务挑战、了解评估标准、确定利益相关者、探索时间表和紧迫性，并获取演示协议。

**AI培训师打开程序。** *您即将与一位学习部副总裁进行发现呼叫，这位副总裁在续订合同之前正在评估LMS供应商。 您的目标是确保后续演示。*

**AI Persona Opener.** *感谢在会议后跟进。 我有20分钟时间 — 说实话，我们已经听过很多供应商的许诺，所以让我们来了解一下细节。*

**评估标准（涵盖的主题）**

| **主题** | **粗细** | **开始或结束** |
|---|---|---|
| 发现提问 | 25% | 否 |
| 业务影响探索 | 20% | 否 |
| 利益相关者识别 | 20% | 否 |
| 成功量度识别 | 15% | 否 |
| 下一步对齐方式 | 20% | 是 |

**典型异议**

* “我们听到了每个LMS供应商都做出的类似承诺。”
* “我们最担心的是移民风险。”
* “我们不相信另一个平台能改善普及率。”

**成功状态。** 学习者可确保后续演示并了解组织的购买流程。

### 客户成功：采用恢复执行审查

**方案。** 平台使用量在前两个季度下降了40%。 执行赞助商已开始对ROI提出质疑，续订讨论将在四个月后开始。 学习者是一名客户成功经理，负责进行季度业务回顾。

**角色**

| **字段** | **详细信息** |
|---|---|
| 姓名 | 迈克尔·亚当斯 |
| 角色 | 来自HR技术的Director |
| 系统个性 | 关系导向 |
| 沟通风格（背景细微差别） | 合作但受挫；想合作寻找解决办法，但对当前的发展轨迹已经失去耐心。 |
| 优先级 | 提高员工参与度；提高经理参与度；证明业务价值 |
| 压力 | 预算削减；新的克罗伊西亚人权组织期望；加强续约审查 |

**人物志问题**

* 低采用率 — 在审阅开始时出现。 很好：学习者直接承认下降，而不是以积极的指标领先。
* 缺乏管理层可见度 — 在讨论报告时会出现。 很好：学习者会建议一个面向主管的特定信息板或报告。
* 报告不充分 — 与能见度相伴而生。 足够好：学习者承诺采用具体的报告节奏。
* 相互竞争的优先事务 — 在提出下一步计划时就会出现。 足够好：学习者建议迈出低投入的第一步，而不是大型计划。

**目标。** 诊断采用挑战，并建立具有明确所有权和时间表的恢复战略。

**AI培训师打开程序。** *您即将与一个平台使用率大幅下降的客户领导季度业务回顾。 您的目标是离开并同意恢复计划。*

**AI Persona Opener.** *我将直接操作 — 使用率下降了40%，而我的克罗问我为什么要为无人使用的平台付费。 我今天需要的不仅仅是安心。*

**评估标准（涵盖的主题）**

| **主题** | **粗细** | **开始或结束** |
|---|---|---|
| 业务回顾效果 | 20% | 否 |
| 根本原因分析 | 25% | 否 |
| 变更管理评估 | 20% | 否 |
| 成功规划 | 20% | 否 |
| 管理协调 | 15% | 是 |

**典型异议**

* “我为什么要相信本季度会有所不同？”
* “我的团队没有时间开展另一项计划。”
* “我需要一些我能展示给克罗尔的东西，而不仅仅是一个计划。”

**成功状态。** 双方在行动、问责制、时间表和可衡量的成果方面达成了一致。

### 领导力发展：管理业绩不佳问题

**方案。** 经理必须处理一名高级员工表现下降的问题，该员工最近错过了最后期限，收到了客户投诉，并与团队协作关系不佳。 这名员工以前是位优秀的执行者。

**角色**

| **字段** | **详细信息** |
|---|---|
| 姓名 | David Lewis |
| 角色 | 高级项目经理 |
| 系统个性 | 坚定 |
| 沟通风格（背景细微差别） | 自信且防守；反击而不是立即接受反馈。 |
| 优先级 | Protect的职业名声；恢复经理的信心 |
| 压力 | 工作量增加；个人压力；对职业发展的关注 |

**人物志问题**

* 不清楚的期望 — 提早出现。 足够好：经理会根据特定的、之前传达的期望地面反馈。
* 不合理的工作负载 — 在对话中提起。 足够好：经理承认工作量是一个因素，但不会错过最后期限。
* 反馈公平性 — 在举出性能示例时出现。 足够好了：这位经理列举了一些具体而真实的例子，而不是一般的印象。

**目标。** 围绕性能改进计划建立理解和达成一致意见。
