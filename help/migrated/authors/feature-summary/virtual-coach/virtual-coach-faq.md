# 虚拟引导常见问题解答

## 创作

获取有关构建、配置和故障排除“虚拟教练”角色扮演的常见问题解答。

1. **为什么我的角色扮演得分为零，即使我涵盖了大部分主题？**
检查您的主题之一是否启用了**建立或中断**。 如果学习者在对话期间根本不谈及成败主题，则无论他们在所有其他方面的表现如何，模拟的最终分数均为0。 为一两个真正不可协商的主题保留成败状态，以避免在合理尝试下发生这种情况。 有关完整设置，请参阅[创建并发布虚拟指导角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)。

2. **多角色角色扮演可以包含多少个角色？**
单个场景中最多可有4个角色，每个角色均单独配置有自己的**角色**、**个性**&#x200B;和&#x200B;**角色顾虑**。 当学习者需要在同一对话（例如购买委员会的推介或执行委员会的审核）中指导多个利益相关者时，请使用此选项。

3. **如何在语音、聊天和视频之间进行选择？**
这取决于您选择的角色类型。 **系统角色**&#x200B;仅支持&#x200B;**声音和视频**（一个带有口语声音的动画头像）或&#x200B;**声音**。 **自定义角色**&#x200B;支持语音交互，您可以单独为支持语音和视频模式的角色启用&#x200B;**视频头像**。 选择“语音和视频”可实现最逼真的模拟，选择“语音”则适用于不需要视觉化头像的场景，例如基于手机的培训。

4. **如何为AI共同创建助理编写良好提示？**
输入概述方案的简短说明，如`Handling price objections in enterprise sales`或`Pitching our new product to a buying committee`。 然后，AI Assistant会询问后续问题以帮助您构建概述、AI角色和评估主题。 尽可能多地提供情景、角色和顾虑，以及您想要如何衡量成功的情况 — 在最初的描述中更详细地描述意味着在聊天中减少来回切换。 请参阅[收集虚拟引导角色扮演的材料](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md)，以获取更完整的提示模板。

5. **角色扮演发布后能否进行编辑？**
是。 对角色设置、主题和其他配置的更改会对任何未发布的角色扮演立即生效。 如果已发布角色扮演并将其分配给学习者，请在做出更改后重新发布，以便学习者看到最新版本。

有关一般产品、许可和管理问题，请参阅[Adobe Learning Manager Virtual Coach常见问题解答](/help/migrated/authors/feature-summary/virtual-coach/virtual-coach-faq.md)。

## 培训与合规

1. **Virtual Coach如何保护客户和学习者数据？**
使用AES-256加密存储客户数据，使用TLS 1.3+保护传输中的数据，并由独特的客户标识符在逻辑上隔开，以确保客户环境之间的隔离。 这些控制措施每年都通过第三方渗透测试来验证。

2. **虚拟引导数据存储在何处并进行处理？**
客户数据存储在欧盟数据中心，支持与欧洲隐私要求保持一致。

3. **Virtual Coach将客户和学习者数据保留多长时间，是否可以将其删除？**
会话数据可以在服务协议期间保留，客户可以配置公司特定的保留策略。 个人用户可以删除自己的录制，管理员可以执行批量删除，并且可以在删除之前导出数据。 还支持自动删除机制和审核日志记录。

4. **客户上传的内容是否用于生成角色扮演之外的其他用途，例如AI培训或产品改进？**
不，客户数据不会用于AI培训。

5. **Virtual Coach如何使用AI，针对AI生成的响应制定了哪些保护措施？**
Virtual Coach使用生成式AI创建交互式角色扮演体验。 已实施多种保护措施，包括针对暴力、仇恨言论、性内容和自残等类别的Azure OpenAI内容过滤器；提示级别的护栏；以及使AI专注于学习和发展用例的上下文控制。 还进行AI安全测试，并使用基于安全的即时转换和先明后拒绝行为等保护机制处理敏感请求。 此外，合同承诺要求披露人工智能产生的产出，并遵守适用的人工智能条例。

6. **Virtual Coach支持哪些隐私和合规性标准？**
Virtual Coach支持与GDPR相关的隐私保护、可配置的保留控制、审核日志记录、用户删除功能和基于EU的数据托管。 合同协议还需要遵守适用的法律和法规，包括《欧盟AI法》和《加利福尼亚州AI透明度法》(SB-942)。

7. **谁拥有上传到虚拟教程的内容以及会话期间生成的内容？**
客户拥有上传到Virtual Coach的内容以及会话期间生成的内容。

8. **Virtual Coach数据驻留在Adobe Learning Manager中或虚拟引导服务提供商的什么位置？**
角色扮演数据存储在Virtual Coach服务提供商的云基础架构中，并托管在欧盟数据中心。

## 产品

1. **如何为现有Adobe Learning Manager客户激活虚拟辅导？**
请参阅[激活虚拟教程](/help/migrated/administrators/feature-summary/virtual-coach/manage-virtual-coach-usage-billing.md#activatevirtualcoach)

2. **虚拟引导激活的有效期是多久，它是如何续订的？**
Adobe Learning Manager中的虚拟引导程序激活在您的加载项订阅合同期内有效。 它不会自动成为永久性的。 有效期与您的订阅期保持一致。

   **续订：**&#x200B;要在您的合同期结束后继续使用虚拟教练，您必须续订您的订阅。 在购买时，Adobe会提供一个激活密钥，帐户管理员可使用它在“帐单”部分启用虚拟辅导。 如果您续订合同，则会在需要保持访问不中断的情况下收到说明和一个新的激活密钥。

   还为每个合同期分配每月活动用户(MAU)积分。 合约结束时任何未使用的积分将失效。 它们不会延续到新的时期。 只要您的付费虚拟教练订阅有效，您的激活即会持续，通过延长订阅即可续订，可通过Adobe帐户进行管理。

3. **在创建或完成角色扮演后，上载的源文档和生成的会话数据会发生什么情况？**
上传的源文档可用于创建和配置角色扮演场景、角色和评估标准。 学习者完成角色扮演后，虚拟教练会生成评估结果、分数、指导反馈和完成信息，以支持学习和报告活动。 根据适用的内容生命周期和保留策略，与角色相关的数据将保持可用。

4. **学习者是否可以重试角色扮演？**
是。 学习者可以多次重复角色扮演会话来练习其技能、应用指导反馈并提高其表现。 完成角色扮演后，学习者可以查看其反馈并开始再次尝试继续发展其技能。

## 一般问题

1. **什么是虚拟教练？**
虚拟教练是Adobe Learning Manager内置的一项人工智能角色扮演和指导功能。 它允许学习者使用具有智能实时响应功能的AI角色练习现实世界的对话，然后收到即时性能报告，其中涵盖了他们的言论和说话方式。 有关完整说明，请参阅[虚拟引导是什么](/help/migrated/authors/feature-summary/virtual-coach/what-virtual-coach-is.md)。

2. **谁使用虚拟教练？**
企业使用Virtual Coach培训销售代表、客户服务团队、呼叫中心客服专员、经理和负责人、新员工、合作伙伴和员工学习新的产品或流程。 虚拟教练可供激活虚拟教练的Adobe Learning Manager帐户中的所有学习者、作者和管理员使用。 学习者访问并完成角色扮演会话，作者创建和发布角色扮演场景，管理员管理积分并查看报告。

3. **虚拟引导是否自动使用我现有的Adobe Learning Manager内容？**
数字 作者必须为他们创建的每个角色扮演提供参考材料，例如行动手册、销售平台、成绩单和评分规则，或书面提示。 Virtual Coach会使用上传的材料和角色定义来推动对话；它不会自动使用内容库或课程中已有的内容。 请参阅[收集虚拟指导角色扮演的材料](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md)以了解要准备的内容。

4. **可以使用哪些类型的角色扮演？**
虚拟教练支持三个领域：销售支持、领导力培养和技能评估。 作者可以从预建的模板中进行选择，这些模板涵盖各种情景，例如B2B发现呼叫、冷呼叫、处理异议、提供困难的反馈以及减少客户投诉。 作者还可以使用AI Assistant从头开始创建自定义场景。 查看[创建和发布虚拟引导角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)。

5. **虚拟引导支持哪些语言？**
虚拟教练提供九种语言的界面和模拟内容：德语（德国）、西班牙语（拉丁美洲）、西班牙语（西班牙）、法语（法国）、意大利语（意大利）、葡萄牙语（葡萄牙）、葡萄牙语（巴西）、荷兰语（荷兰）和英语。

6. **如何许可和计费虚拟教练？**
虚拟教程可作为Adobe Learning Manager的附加订阅提供。 使用情况以每月活动用户(MAU)衡量。 学习者在一个日历月启动课程时，会使用MAU积分；该月同一学习者的其他会话不使用额外积分。 于年度合约结束时尚未使用的信用额度。 请参阅[管理虚拟引导的使用和计费](/help/migrated/administrators/feature-summary/virtual-coach/manage-virtual-coach-usage-billing.md)。

7. **学习者的分数是如何计算的？**
每个会话都会生成“知识”分数和“样式”分数。 知识分数反映学习者是否解决了所需主题并提供了准确的信息。 风格分数反映学习者的沟通方式，包括节奏、清晰度、填充词、句子强度和声音能量。 作者在配置方案时设置每个组件的权重；常见的配置是70%知识和30%样式。 请参阅[了解您的虚拟引导性能报告](/help/migrated/learners/feature-summary/virtual-coach/understand-virtual-coach-performance-report.md)。

8. **学习者是否可以下载其性能报告？**
是。 除了在屏幕上查看报告外，学习者还可以下载此报告，将其作为PDF保存，以供自己保存记录或与经理共享。

9. **学习者是否可以重试角色扮演？**
是。 学习者可以尝试任意多次发挥角色。 每次尝试都是新的独立会话，并生成新的性能报告。 只有日历月中的第一个会话会使用MAU积分。

10. **学习者能否提交其答疑以供人工审核？**
数字

11. **移动设备上是否提供虚拟辅导？**
Adobe Learning Manager桌面和移动Web上以及API都支持虚拟教程。 在当前版本的Adobe Learning Manager移动应用程序(iOS/Android)中无此选项可用。

12. **学习者数据是否用于训练AI？**
数字 虚拟教练托管在符合GDPR规范的基础架构上，不使用个人学习者数据来训练AI模型。

13. **工作辅助和虚拟教练课程模块有何区别？**
工作辅助是一种独立的按需资源，学习者无需注册课程即可随时直接从目录访问。 课程模块作为结构化课程序列的一部分进行访问，包括注册、完成跟踪和正式评估。 相同的角色扮演可以发布为工作辅助，并同时添加到多个课程。 请参阅[向课程添加虚拟教练角色扮演](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md)。

14. **在推出新流程或产品时，我们应该如何打包Virtual Coach？**
将课程或学习旅程中的角色扮演与相关培训内容打包在一起，并通过电子邮件或其他更改管理通信分发课程链接。 虚拟教练最适合定位为培训的最后一英里 — 学习者完成相关内容后立即建立检查点，在那里学习者可以证明自己可以应用它，而不是作为一项单独的活动进行。

15. **无头或API实现是否支持虚拟辅导？**
用于获取课程和工作辅助的公共API还可获取虚拟教练课程和工作辅助。 `jobAidType`筛选器专门可用于获取虚拟指导工作辅助。 无头播放器支持虚拟指导内容，流体播放器中包含虚拟指导的课程和工作辅助工作。

有关构建和配置角色扮演的问题，请参阅此常见问题解答页面。
