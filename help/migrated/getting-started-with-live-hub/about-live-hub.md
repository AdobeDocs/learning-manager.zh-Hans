# 关于Live中心

Live Hub可将虚拟教室以本机方式引入Adobe Learning Manager，因此，您的学习管理系统(LMS)和会议工具之间无需切换。 系统会自动跟踪每个会话，功能丰富的会话信息板会显示讲师的参与情况，且远远超出出勤率。

专为实时培训而构建，实时中心中的AI代理在整个过程中与讲师一起工作。 他们建议投票，检测参与者问题并提出答案，实时监控分组讨论室并生成会话摘要，以便讲师可以专注于提供培训会话。 对于学习者而言，录制内容会自动分割为可导航的主题，从而使重播像参加实时活动一样结构化和有用。

实时中心可帮助讲师提供引人入胜的虚拟培训，并帮助组织大规模运行交互式实时培训。

>[!NOTE]
>
>Adobe Learning Manager即将于&#x200B;**8月发布**，届时可访问Live Hub。 该功能发布后，即可获得有关Live Hub的文档。
