# 关于举手和反应

讲师和参加者可以使用举手和反应功能在实时中心会话期间进行互动。 学习者举手发出想说话的信号，并做出反应以提供快速的非口头反馈。 讲师可以实时查看反应和举手来管理参与，所有这些操作都不会中断会话流程。

## 主要优点

举手和反应特性提供以下好处：

* **鼓励参与**：让学习者发出信号，表明他们想发言或提问，同时不要中断会话。

* **收集快速反馈**：使学习者能够快速做出反应，如拇指向上、掌声或思考，让讲师可以即时感受到教室的情况。

* **管理交互**：允许讲师放下单个学习者的手或清除所有举起的手，以保持讨论井然有序。

* **保持无中断**：通过实时显示的视觉提示和反应支持参与，而无需暂停会话流。

## 角色和权限

讲师和学习者均可在实时中心会话中举手发表反应，但可用操作取决于用户的角色。
