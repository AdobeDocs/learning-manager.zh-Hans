# 关于与会者面板

讲师可通过Live Hub中的“与会者”面板查看学习者并管理其在会话期间的互动。 它可提供所有与会者的集中视图，并帮助讲师实时监控参与和参与情况。

该面板会显示与会者姓名、角色和交互状态，从而轻松识别会话中的现有人员以及尚未加入的人员。 讲师可以使用面板管理参与者权限、监控参与情况和控制学习者交互，例如访问麦克风、做出反应以及举手。

## 主要优点

* **提高会话可见性**：在一个位置显示所有与会者，从而更轻松地查看已加入的人员。

* **轻松管理参与情况**：提供对与会者控件的快速访问，帮助讲师管理会话期间的学习者交互。

* **支持学习者互动**：通过反应、举手和私人消息等功能实现参与。

* **跟踪出席情况**：显示当前在场以及已注册但尚未加入会话的学习者。

## 角色和权限

在实时中心会话中，讲师和学习者均可使用“与会者”面板。 可用操作因用户角色而异。
