# 关于分组讨论

分组讨论区允许讲师将实时中心会话拆分为更小的组。 学习者加入这些会议室进行讨论、活动或协作，并在活动结束后自动返回主会话。 分组讨论室对于集思广益、分组活动和重点学习非常有用。

讲师可以创建和管理分组讨论室、为学习者分配任务以及使用说明指导活动。 在会话期间，讲师可以监控会议室活动、查看实时讨论摘要并在需要时提供支持。

学习者可以使用共享说明和摘要在指定的会议室中协作、参与讨论并与活动保持同步。

会议结束后，讲师可以通过会议报告和“会议”信息板查看分组讨论情况和结果，从而更好地进行分析和跟进。

## 分组讨论会的好处

* **鼓励协作**:Participants&#x200B;可以在较小的小组中进行协作，以便进行重点突出的讨论和活动。

* **实时会议室可见性**：讲师可以在不中断参与者的情况下跨会议室监控参与、参与和帮助请求。

* **AI支持的讨论见解**：实时摘要可帮助讲师快速了解不同会议室中的讨论并有效地指导活动。

* **结构化活动指南**：提供指导学习者在分组活动期间的说明。

* **灵活的参与者管理**：可以轻松分配和调整参与者以支持不同的学习格式。

* **会话后洞察和报告**：讲师可以在会话信息板中查看摘要、报告和会话数据，以分析结果并改进未来的会话。

## 分组讨论会话术语

这些术语解释了分组讨论会的工作原理以及参与者在活动期间如何进行互动。

| **期限** | **描述** |
|----|----|
| **分组会话** | 虚拟教室中的临时会话，其中参与者分为若干个较小的组，以便进行重点讨论或活动。 |
| **临时会议室** | 分组讨论会中分为小型组，学习者可参与特定活动。 |
| **分组说明** | 讲师将任务或讨论分配给分组讨论室的参与者。 |
| **分组报告** | 讲师在分组讨论会期间对学习者参与程度的度量，供其用于监测和评估参与级别。 |

## 分组讨论会话工作流

分组讨论会遵循结构化流程，包括设置、实时协作和会议完成。

### 设置分组讨论

在开始分组讨论会话之前，讲师需要根据会话要求创建和配置分组讨论室。

* 定义分组讨论区的数量。

* 自动或通过拖放参与者来手动将学习者分配给会议室。

* 添加活动说明以指导学习者。

此设置可确保在会话开始之前，学习者已按照活动进行组织和调整。

### 在分组讨论会期间

分组讨论开始后，学习者将被移动至其分配的会议室，以协作处理给定活动。

* 学习者可以在分组会议室中进行互动和参与。

* 讲师可以监控会议室活动、跟踪参与情况并响应帮助请求。

* 讲师可以查看实时讨论摘要并加入会议室，以便在必要时为学习者提供指导。

这一阶段的重点是协作和积极参与。

### 分组讨论会之后

当分组讨论会话结束时，所有参与者都会自动移回主会议室。

* 学习者返回到主会话视图。

* 讲师可通过报告审阅总体活动、结果和会议摘要。

* 讲师可以创建重复会话，以便重复使用相同的设置开展将来的活动。

这将标记分组活动的完成情况并启用会话后审阅。
