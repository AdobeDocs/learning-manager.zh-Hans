# 关于“聊天”面板

通过Live Hub中的“聊天”面板，讲师和学习者可以在实时会话期间实时沟通。 它支持公开讨论、私人对话和结构化问题处理，帮助讲师高效管理互动，同时让学习者保持参与。

## 主要优点

* **改进了交互**：支持讲师和学习者之间的实时通信。

* **结构化讨论**：分别针对“所有人”、“私人”和“问题”的选项卡可让对话保持有条不紊。

* **高效的问题处理**：AI支持的帮助可帮助讲师快速识别问题并做出响应。

* **审核控制**：讲师可以管理和维护富有成效的讨论环境。

* **上下文通信**：回复和提及功能可确保对话的清晰度。

## “聊天”面板选项卡

“聊天”面板包含多个选项卡，可帮助在Live Hub会话期间管理不同类型的对话。

* **所有人**：使用此选项卡发送和查看所有参与者都可见的消息。 AI还会从此选项卡中发布的消息中检测学习者问题。

* **私密**：使用此选项卡可在会话期间与特定参与者进行一对一对话。

* **问题**：此选项卡显示AI在公共聊天中识别的问题。 讲师可以高效地查看、分组和回答问题。

>[!NOTE]
>
> **问题**&#x200B;选项卡仅对讲师可用。
