# 关于投票

通过“轮询”功能，讲师可以在实时会话期间创建和启动轮询，以实时收集学习者的响应。 您可以通过选择问题类型（如多选、多答或简答）手动构建投票，或使用破冰机投票和知识检查投票等AI辅助选项快速生成投票。

学习者可以响应活跃的投票，更新他们的答案，并查看共享结果。 从&#x200B;**投票和测验**&#x200B;面板管理所有投票活动。

## 主要优点

* **提高学习者参与度**：通过允许学习者在会话期间回答问题而不是收听，鼓励积极参与。

* **实时检查理解情况**：评估学习者对主题的了解程度并确定可能需要进一步说明的区域。

* **使用破冰者开始会话**：在会话开始时进行投票，以便让参加者暖场，鼓励提前互动，并创建更吸引人的学习环境。

* **收集即时反馈**：在继续会话时，无需暂停正在进行的说明或内容共享，即可实时收集学习者的意见、首选项或反馈。

## 角色和权限
