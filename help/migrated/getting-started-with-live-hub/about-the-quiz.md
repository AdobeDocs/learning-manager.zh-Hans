# 关于测验

讲师可通过Live Hub中的测验功能创建和执行测验，以在实时会话期间评估学习者对测验的理解。 您可以在会话之前或会话期间创建测验，启动它们以实时收集响应，并在学习者在“会话”信息板中进行响应时监视结果。

>[!NOTE]
>
> 实时中心会话中的测验与在Adobe Learning Manager **测验创建工具**&#x200B;中创建的测验不同。

## 主要优点

测验功能提供以下优势：

* **评估学习结果**：评估学习者在完成教学后对关键概念的理解和保留程度。

* **进行结构化评估**：创建多问题测验，以跨主题或模块评估学习者，而非单个问题检查。

* **跟踪个人绩效**：实时测验结果可帮助讲师快速了解整个团队的绩效，并识别可能需要进一步澄清的领域。

* **提高参与度**：通过交互式评估鼓励积极参与。
