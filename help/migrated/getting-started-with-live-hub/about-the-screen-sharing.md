# 关于屏幕共享

通过屏幕共享，讲师可以从其设备与参与者实时共享内容。 通过屏幕共享展示应用程序、演示演示演示文稿、演示工作流程并指导学习者完成任务。 当讲师启用屏幕共享时，学习者还可以共享其屏幕。

除了共享屏幕之外，您还可以在“拆分视图”中并排显示两个内容、在共享内容旁使用白板，以及直接在屏幕上批注以突出显示关键信息而不中断演示。

## 主要优点

* **实时呈现**：直接从您的设备共享应用程序、演示文稿和工作流程，以便学习者能够全程参与。

* **一次显示更多**：在拆分视图中最多并排显示两个内容（例如屏幕共享和白板），无需来回切换。

* **直观地解释**：直接对共享内容进行批注，以突出显示关键点、澄清概念并引导学习者的注意力。

* **组合工具**：在共享屏幕旁运行白板，以便在您演示时添加说明和备注。

* **鼓励参与**：让学习者共享自己的屏幕以展示其作品或支持讨论，而讲师可以完全控制会话。

## 角色和权限

讲师和学习者均可共享屏幕。 可用操作因用户角色而异。
