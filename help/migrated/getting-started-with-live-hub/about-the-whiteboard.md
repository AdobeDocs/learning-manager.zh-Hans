# 关于白板

白板是实时中心会话中的共享数字画布，讲师和学习者可以实时协作处理。 它的工作方式类似于课堂白板，但在线上：您可以在多个讨论区中徒手绘制、添加形状和文本、批注创意和组织内容，所有这些操作对会话中的每个人都可见。

白板可帮助您：

* 使用视觉辅助解释复杂主题。

* 在实时会话期间与学习者互动协作。

* 在多个讨论区和页面之间组织内容。

讲师可以在实时中心中共享白板，以直观地解释概念、批注想法并与学习者实时协作。 白板提供了一个共享画布，其中包含绘图工具、形状、文本、缩放控件和协作功能。 当讲师启用编辑权限时，学习者还可以绘制、添加形状和擦除内容。

## 角色和权限

讲师和学习者均可通过实时中心会话使用白板。 可用操作因用户角色而异。
