# 管理员在Live Hub会话中的角色

作为Adobe Learning Manager (ALM)的管理员，您可以配置和管理提供实时中心培训所需的关键组件。 这些功能有助于简化讲师指派、课程设置、品牌推广和报告的过程。

本文概要介绍了管理员与Live Hub会话相关的操作。 有关详细的配置步骤和工作流程，请参阅每一节中链接的文章。

## Live Hub的管理员功能

作为管理员，您可以使用以下功能设置和运行实时中心培训。 选择链接文章以了解详细步骤。

| **功能** | **您可以做什么** | **了解详情** |
|----|----|----|
| **启用实时中心** | 为Adobe Learning Manager帐户启用Live Hub。 您还可以启用在Live Hub会话期间支持作者和讲师的AI智能助理，包括： <ul><li>投票助手</li><li>问答助手</li><li>分组监视助手</li><li>录制主题生成器</li><li>讲师查找器助手</li></ul> | [启用实时中心功能](../administrators/feature-summary/enable-live-hub.md) |
| **管理讲师配置文件** | <ul><li>定义讲师角色和职责</li><li>分配技能和专业知识</li><li>设置可用性和教学首选项</li><li>通过讲师查找器启用更智能的建议</li></ul> | [添加和管理讲师](./instructor-management.md) |
| **添加批量技能** | <ul><li>批量添加技能</li><li>组织和更新技能集</li><li>根据课程要求调整技能</li></ul> | [创建、修改技能和级别](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **管理假日** | <ul><li>添加一个假日，或者通过上传CSV文件一次导入多个假日</li><li>为每个假日设置日期、名称和可选说明</li><li>在“全部”、“即将到来”和“过去”选项卡中审阅、搜索和筛选假日</li><li>维护一个一致的全帐户假日日历</li></ul> | [管理假日](./manage-holidays.md) |
| **配置品牌推广和颜色主题** | <ul><li>应用颜色主题</li><li>跨会话保持一致的视觉标识</li><li>通过品牌环境增强学习者体验</li></ul> | [颜色主题](../administrators/feature-summary/themes.md#color-themes) |

>[!NOTE]
>
>有关Live Hub常见问题的解答，请查看[Live Hub的常见问题](./frequently-asked-questions-for-live-hub.md#administrator)。
