# 作者在Live Hub会话中的作用

作为Adobe Learning Manager中的作者，您可以创建和管理虚拟教室课程，这些课程使用Live Hub提供讲师指导的实时培训。 您可以设置课程、配置会话、分配讲师并发布课程，以便可以运行会话。

本文介绍了作者使用Live Hub时执行的操作。

## 作者可以执行的操作

作者在创建Live Hub课程时负责执行以下任务。

### 创建实时中心课程

作者可以在创建课程的工作流程中创建实时中心课程。 您可以：

* 将虚拟教室模块添加到课程中。
* 选择Live Hub作为实时虚拟培训工具。
* 定义会话详细信息，如标题、描述和持续时间。

### 配置会话详细信息

作者可以定义实时中心会话的执行方式。 您可以：

* 设置日期、时间和时区
* 配置会话持续时间

### 使用“讲师查找器”分配讲师

使用“讲师查找器”根据课程类型查找和分配讲师。 您可以：

* 根据课程要求、技能和可用性，获取AI支持的讲师建议。
* 为会话选择一个或多个合格的讲师。
* 通过智能建议和简化的讲师分配加快课程设置。

### Publish和管理课程

完成配置后，作者便可以完成并管理课程交付。 您可以：

* Publish面向学习者的课程
* 更新会话详细信息（如果需要）
* 管理课程结构和模块

有关详细信息，请查看[创建Live Hub会话](./create-a-live-hub-session.md)。
