# Live Hub (Beta)会话的最佳实践

Adobe Learning Manager中的实时中心课程将讲师和学习者聚集在一起，提供实时培训，包括聊天、投票、测验、白板、分组讨论室、录制和分析。 本文说明如何执行每项任务。 这份文件是它的伴侣：它解释了如何做好这些工作。

每个实时中心会话都经历三个阶段。 本指南遵循相同的节奏，确定会话成功的大部分努力发生在任何人加入会议室之前。

## 为会话做准备

全面的准备有助于确保流畅、引人入胜的虚拟教室体验。 在学习者加入之前，请配置课程、准备活动并确认您的会议室已做好交付准备。

### 启用实时中心功能

管理员必须先为ALM帐户启用Live Hub功能，作者才能创建Live Hub课程。 确认首先打开此设置，以便以后不阻止课程创建、注册和计划。

确认您帐户的许可或订阅计划包括Live Hub。 如果该选项未显示在管理员设置中，请先向Adobe支持确认授权，然后再进一步执行故障诊断。

启用该功能后，请通知作者和讲师，以便他们能够立即开始设计课程和准备会话。

### 设计清晰易懂的课程

作者在创建课程时，应使用清晰且具有描述性的标题，以便学习者了解课程目的。 添加简要说明，说明学习者期望学习或完成的内容。

定义课程开发的技能，并分配适当的技能级别和积分值。 准确的技能表可帮助学习者发现相关培训并提高报告的准确性。

在创建课程时指定讲师，以便他们有足够的时间来查看内容、准备活动并熟悉会议室设置。

### 提前注册学习者

提前注册学习者，以便在课程开始之前提前通知他们。 学习者会根据您的Adobe Learning Manager配置，在平台中收到通知或通过电子邮件收到通知。

对于开放式培训计划，请考虑启用自助注册，以便学习者可以直接从课程目录注册并从&#x200B;**我的学习**&#x200B;中访问课程。

在发布课程之前，请确认您的帐户已启用学习者通知，以确保成功传递邀请和提醒。

### 在会话开始之前加入会议室

以讲师的身份在计划开始时间前至少10-15分钟加入会议室。 这样，您可以在学习者到来之前验证音频和视频设备、测试屏幕共享并解决任何技术问题。

使用此准备时间可配置会议室设置、审核活动并确保所有会话资源均可用。

### 配置参与者权限

在会话开始之前查看参与者权限。 仅在活动需要屏幕共享和白板访问等功能时才启用这些功能。

提前配置权限有助于在会话期间保持专注，并减少在学习者等待期间进行调整所导致的中断。

### 准备投票和测验

在会话前创建投票和测验，以便在需要时可用。

考虑从打破陈规的投票开始，以鼓励参与并帮助学习者从课程开始就有参与感。 您还可以创建与学习目标相符的知识检查问题，并强化关键概念。

如果您需要在会话期间提高参与度，请准备其他要启动的投票或测验问题。

### 设置协作工具

如果打算使用第三方协作工具（如Miro），请在学习者加入会话之前登录并配置这些工具。

提前连接并验证协作工具有助于避免在实时会话期间因登录提示或帐户验证而造成的中断。

### 配置临时会议室

如果您的培训包括分组讨论活动，请在会话开始之前创建和配置分组讨论室。

定义会议室数量，设置持续时间，并为每项活动提供明确的说明。 如果不同的组需要不同的任务，请添加特定于工作室的说明。

根据您的培训需求选择参与者分配方法：

* **自动分配**：自动在分组会议室之间分配参与者。

* **手动分配**：允许讲师将参与者放入特定会议室。

### 上传AI参考材料

如果您的会话使用AI辅助的问答功能，请在会话开始之前上传支持材料。

添加演示幻灯片、文档或学习者需要参考的其他源材料。 提供相关内容有助于AI生成更准确、与会话目标一致的响应。

使上传的材料保持最新，并仅包括与培训课程相关的内容。

## 在会话期间

课程开始后，将重点放在明确提供内容、鼓励参与以及适应学习者参与上。 使用可用的协作和推动工具创建交互式学习体验。

### 开始录制和转录

在会话开始时开始录制，捕捉完整的学习体验以供将来回放。 记录还会生成一个成绩单，学习者可以在会话结束后使用该成绩单来回顾关键讨论和概念。

通知学习者正在录制会话，以便在讨论开始之前明确期望。

### 有效地共享内容

共享内容时，尽可能仅共享演示文稿所需的应用程序窗口或浏览器选项卡。 限制可见内容有助于学习者集中注意力，并防止不相关的信息出现在屏幕上。

使用批注工具突出显示重要信息、强调关键概念并引导学习者在演示期间集中注意力。 您还可以保存注释内容的快照，以供将来参考。

如果学习者需要演示或演示内容，请根据需要授予屏幕共享权限。 共享内容的参与者还可以使用可用的批注和快照工具来支持其演示文稿。

### 管理讨论和问题

使用聊天和问答区域可以组织对话并高效地回答学习者问题。

* **所有人**：用于打开的讨论和组对话。

* **问题**：用于收集并回答学习者问题。

* **私有**：用于一对一通信，不会中断会话。

如果AI辅助的答复可用，则使用它们生成问题的草稿答案。 在发布之前查看和编辑回复，确保回复准确且适合您的受众。

鼓励学习者通过聊天进行参与，尤其是在麦克风访问可能受限的大会议中。 确认会议期间提出的问题和评论意见，以促进参与和参与。

### 监控参与情况

使用&#x200B;**与会者**&#x200B;面板跟踪会话期间的参与者活动。 该面板可帮助您识别现场人员、查看有人举手和作出的反应，并在必要时与学习者私下沟通。

您还可以使用全房间控件（例如，将所有麦克风静音或清除举手）来帮助管理活动之间的过渡。 仅在需要维护有组织的学习环境时才使用这些控件。

### 使用投票和测验来提高参与度

在整个会话中启动投票和测验，以检查理解情况并鼓励参与。

考虑使用：

* 在教授概念后，**进行测验**&#x200B;以评估学习者对概念的理解。

* **投票**&#x200B;以收集意见、收集反馈或指导小组决策。

共享投票或测验结果有助于在进入下一个主题之前进行讨论，并提供机会澄清误解。

### 监控参与人参与情况

使用会话会议室顶部的&#x200B;**参与者参与**&#x200B;指示器实时跟踪整体参与者参与。 使用这些见解调整节奏、鼓励互动或修改活动，以使参加者在整个会话期间保持参与。

| **参与级别** | **指示器** | **建议的操作** |
|----|----|----|
| **高** | 绿色 | 继续当前活动。 考虑引入讨论、测验或分组活动，以在学习者参与的基础上进一步发展。 |
| **中** | 黄色 | 通过提问、发起调查或鼓励他人通过聊天参与来重新吸引学习者。 |
| **低** | 红色 | 更改活动格式。 考虑使用意见调查、分组活动、讨论提示或步调调整来重新获得学习者的注意力。 |

### 促进分组活动

在学习者准备好开始组活动时启动分组讨论室。 如果在会话之前配置了临时教室，则学习者可以在中断最小的情况下进入其指定的教室。

通过在会议室之间切换、响应学习者协助请求以及审阅AI生成的会议室摘要来监控分组活动。 这些摘要概述了每个会议室中正在进行的讨论，帮助您评估学习者进度，确定可能需要指导的会议室并决定何时加入对话。 摘要会随着讨论的发展在整个分组讨论会中自动更新。

如果参与者使用&#x200B;**寻求帮助**&#x200B;选项，请加入会议室提供指导或回答问题。 您还可以在分组讨论室中使用聊天、屏幕共享和白板等协作工具来支持群组活动。

活动完成后，结束分组讨论以使所有参与者返回主会议室。 汇报活动并邀请各组与班级其他成员分享重要收获。 在会话之后，查看分组讨论报告或会话仪表板，以访问按会议室划分的摘要、参与者详细信息和其他分组讨论见解。

## 会话之后

在会话结束后，查看录制和会话分析以支持学习者，评估参与度并改进未来的交付情况。

### 为所有参与者结束会话

会话完成后，为所有参与者结束会议室。 这可确保每个人同时退出会话并将定向到完成屏幕，在该屏幕中，他们可以返回课程并提供有关其学习体验的反馈。

鼓励学习者在离开课程之前提交反馈。 学习者反馈可帮助您识别技术问题、完善简化技术并改进未来的会话。

### Publish录制

会话结束后，请从&#x200B;**会话** > **概述**&#x200B;页面访问录制，并在与学习者共享之前进行审阅。

使用编辑工具移除设置活动、暂停或其他非必需内容，以便学习者可以专注于教学材料。

在录制过程中生成的成绩单提供了额外的学习资源，因为成绩单可搜索内容，使稍后查看会话的学习者更容易访问。

### 分析会话性能

查看会话分析以了解学习者参与情况并确定改进机会。

使用可用的分析视图评估会话的各个方面：

| **分析区域** | **描述** |
|----|----|
| **会话摘要** | 查看出席情况、会话持续时间、录制可用性和整体会话详细信息。 |
| **交互** | 评估学习者在投票、测验、分组讨论、问答、反应和其他互动活动中的参与情况。 |
| **参与者活动** | 确定个别学习者的参与级别并确定是否需要其他支持。 |
| **报告** | 下载用于记录保留、分析或与利益相关者共享的会话和交互报告。 |

查看这些见解可以帮助您确定哪些活动最有效，以及学习者遇到挑战的位置。

### 将吸取的经验教训应用于今后的会议

使用分析和学习者反馈优化未来的交付。

例如，如果在特定活动期间参与率下降，请考虑在以后的会话中调整格式、节奏或时间。 如果一项民意调查引发了激烈的讨论，或者一项突破性活动被证明是有价值的，那么就把类似的方法纳入即将到来的培训中。

持续改进有助于随着时间的推移创造更具吸引力且更有效的学习体验。

### 跟进学习者

在会话后查看参与者活动，并确定可能受益于其他支持的学习者。

考虑与错过会话或无法完全参与的学习者共享录音、成绩单、课程资源或任何后续评估。 提供对这些资源的访问有助于学习者与课程目标保持一致，并在现场活动后继续学习。
