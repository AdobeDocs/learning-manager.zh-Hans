实时中心包括管理员、作者、讲师和学习者角色，他们分别负责培训工作流程的不同部分。 本文档按照角色对原始Live Hub FAQ内容进行重新组织，以便每位受众可以快速找到与他们最相关的问题。

## 管理员

+++如何为Adobe Learning Manager帐户启用Live Hub？

以管理员身份登录，然后在“学习”>“Live Hub”中导航到AI。 打开此帐户的“启用实时中心” ，以便实时中心可用于虚拟教室培训。 启用后，作者可以在Adobe Learning Manager中创建实时中心会话。

+++

+++能否将Live Hub设置为默认虚拟教室提供商？

是。 启用实时中心后，打开将实时中心设置为默认实时培训工具。 创建虚拟教室模块时，会预先选择Live Hub，但您仍然可以根据需要选择其他提供商。

+++

+++管理员可以为实时中心会话启用哪些AI助理？

管理员可以在Live Hub中启用AI，并选择作者和讲师可以使用的AI助理。 可用的助理包括：

* 投票助手：使用AI生成投票。
* 问答助手：帮助过滤学习者问题和草稿回复。
* 分组讨论监视助手：监视分组讨论室讨论。
* 录制的主题生成器：从录制创建结构化主题和注释。
* 讲师查找器助手：为使用AI的会话推荐合适的讲师。

+++

## 作者

+++Live Hub是否适用于我的帐户？

Live Hub (Beta)将从2026年8月开始提供。 管理员可以为您的Adobe Learning Manager帐户启用或禁用Live Hub。 如果启用了实时中心，作者可以在创建虚拟教室模块时将其选为实时培训提供商。 如果“实时中心”选项不可用，请联系您的管理员以为您的帐户启用该功能。

+++

+++如何创建实时中心课程？

登录Adobe Learning Manager并选择“创建课程”。 在“课程目录”页面上，选择“添加”，输入课程名称和说明，然后向“课程目录”中添加模块。 将模块配置为虚拟教室，然后选择Live Hub作为交付工具。 必须先为您的Adobe Learning Manager帐户启用Live Hub，然后才能显示为可用的实时培训提供商。 如果您在可用选项的列表中未看到Live Hub，请与您的管理员联系。

+++

+++如何将课程配置为实时中心会话？

作者可以创建课程并添加虚拟教室模块。 在模块设置中，选择Live Hub作为实时培训提供者，然后输入所需的会话详细信息，如标题、说明、日程安排和时区。 保存模块以在Live Hub中安排会话。

>[!NOTE]
>
>Live Hub必须由管理员为您的Adobe Learning Manager帐户启用，然后才能显示为可用的实时培训提供商。

+++

+++我可以在创建课程时添加讲师吗？

是。 选择“实时中心”后，向会话添加一名或多名讲师，然后选择“添加”>“保存”。

+++

+++如何发布实时中心课程？

完成课程配置后，选择“保存”>“Publish”。 发布后，课程即可用于学习者注册和会话安排。

+++

## 讲师

### 加入会话

+++如何以讲师身份加入Live Hub会话？

登录Adobe Learning Manager并在“即将开始的会话”下找到会话。 选择“会话URL”以打开“预加入”屏幕，然后选择“加入”以进入会话。

+++

+++我可以在与会者到达之前加入会话吗？

是。 讲师可以在会话的计划开始时间之前加入会话，以准备会议室、上传AI应答引用的内容、配置设置，并在参与者加入之前验证一切就绪状态。

+++

+++在会话开始之前，我可以设置什么？

在会话开始之前，讲师可以通过配置学习者权限、创建投票和测验、设置分组讨论室、连接Miro以进行协作以及上传参考资料来准备虚拟会议室，以便在会话期间支持AI问答。

+++

### 学习者权限和隐藏字幕

+++如何允许参与者共享其屏幕并使用白板？

在会话会议室中，从控制栏中选择“设置” ，然后选择“参与者权限” 。 启用“共享”屏幕和“使用白板”，然后选择“完成”以应用更改。

+++

+++何时应配置参与者权限？

在课程开始之前，请先配置学习者权限，为会议室做准备。 这样可确保参与者在加入时具有适当的协作和参与能力。

+++

+++如何打开隐藏式字幕？

从控制栏选择更多选项，选择字幕，然后启用显示字幕。

+++

+++为什么应使用隐藏式字幕？

隐藏字幕在会话期间将口语内容显示为文本，从而提高了辅助功能。 它们可帮助学员更轻松地关注讨论，并为各种学习和倾听环境中的学员提供支持。

+++

### 投票

+++生成AI支持的破冰机投票需要哪些信息？

要生成AI支持的破冰机投票，请提供模块名称和模块说明。 Live Hub使用此信息创建入门问题，帮助学习者在课程开始阶段就参与其中。

+++

+++生成AI支持的知识检查投票需要什么？

AI支持的知识检查轮询从会话转录文本生成。 在生成知识检查轮询之前，确保转录可用且已捕获足够的会话内容。 生成的问题基于会话期间所讨论的主题。

+++

+++如何创建投票？

打开“投票和测验”面板，然后选择“投票”选项卡。 手动创建投票或使用AI生成投票，然后选择保存。 投票将添加到会话中，并且可在需要时启动。

+++

+++我是否可以使用AI生成投票？

是。 Live Hub可以生成AI支持的投票，以帮助在会话期间提高学习者的参与率。

* 选择“破冰机”以生成AI支持的介绍性投票。
* 选择“知识检查”以生成意见调查，帮助评估参与者对正在讨论的主题的理解。

+++

+++能否创建自己的投票问题？

是。 选择“自行构建”以使用自己的问题和响应选项创建自定义意见调查。

+++

+++如何在会话期间启动投票？

在“投票和测验”面板中，选择“投票”选项卡，然后创建新的投票或选择以前保存的投票。 选择启动以使参与人可以使用轮询。 参与者可以实时提交回复，收到回复后会自动收集结果。

+++

+++是否可以让参加者查看投票结果？

是。 启动投票时，请启用“显示所有学习者显示结果”以在会话期间与参与者共享结果。

+++

+++我应该在何时使用投票？

在整个会话期间，使用投票鼓励参与、收集反馈、开始讨论或评估学习者对问题的理解。 知识检查投票对于在进入下一部分之前衡量对关键主题的理解力尤为有用。

+++

### 测验

+++如何创建测试？

打开“投票和测验”面板并选择“测验”选项卡。 选择“创建新测验”，选择问题类型，添加问题和答案选项，确定正确答案，然后选择“完成”。

+++

+++支持哪些问题类型？

Live Hub支持以下测验问题类型：

* 多项选择：参与者选择一个正确答案。
* 多个答案：参与者选择所有适用的答案。

+++

+++如何向测试添加更多问题？

创建测验时，选择+添加问题可添加其他问题。 完成添加问题后，请选择“完成”。

+++

+++如何在会话中启动测试？

在“投票和测验”面板中，选择“测验”选项卡，找到要使用的测验，然后选择“启动”。 参加者可以实时响应测验。

+++

+++能否让参加者查看测验结果？

是。 启动测试时，启用“向所有学习者显示结果”以在会话期间与参与者共享结果。

+++

+++我应该在何时使用测验？

在会话期间，使用测验评估学习者对知识的理解、强化关键概念并衡量知识保留程度。 测验可以帮助您确定可能需要其他解释或讨论的主题。

+++

### 白板

+++如何在Live Hub会话期间创建白板？

从会话控制栏中选择更多选项，然后选择共享白板>新建白板。 白板将立即打开，并且会话中的所有参与者都可以看到。

+++

+++能否重新打开之前在会话期间共享的白板？

是。 选择“更多选项”>“共享白板”，然后从可用白板列表中选择白板。 此时会打开选定的白板，所有学习者都可以看到。

+++

+++我是否允许参与者协作处理白板？

是。 打开白板菜单并启用允许参与者绘制。 学习者可以在白板上绘制、添加形状、插入文本和使用可用的批注工具。

+++

+++我可以保存或导出白板以供将来参考吗？

是。 打开白板菜单，然后选择导出快照。 当前白板内容将导出为PNG图像并下载到您的设备。

+++

+++能否在会话期间管理多个白板？

是。 使用“白板”面板查看和管理会话期间创建的所有白板。 在该面板中，您可以共享白板、删除单个白板或删除所有白板。

+++

### 与Miro协作

+++我可以使用米罗做什么？

Miro提供协作工作区，用于在实时中心会话期间进行集思广益、构思、规划和其他交互式活动。 参与者可以在共享讨论区中实时协作。

+++

+++如何将Miro连接到Live Hub会话？

在会议室中，选择更多应用程序，然后选择“镜像”>“登录到Miro”。 此时会打开一个登录窗口，允许您连接Miro帐户。

+++

+++我需要有Miro帐户才能使用Miro吗？

是。 您必须先使用Miro帐户登录，然后才能将Miro连接到Live Hub会话并访问Miro主板。

+++

+++如何登录到Miro？

选择“登录到Miro”后，选择要使用的帐户并完成登录过程。 连接后，您可以直接从会话访问Miro。

+++

### 临时会议室

+++休息室是做什么用的？

分组讨论室允许您将参与者分为更小的组，以便进行讨论、协作活动、解决问题练习和基于团队的学习。

+++

+++如何创建临时会议室？

打开“分组讨论”面板，输入分组讨论会话的名称，指定会议室数量和持续时间，分配参与者，添加说明，然后选择“保存”。

+++

+++如何将参加者分配到分组讨论室？

您可以选择“自动分配”以自动分配参与者，或者通过将参与者拖动到特定会议室来手动分配参与者。

+++

+++每个临时会议室可以有不同的说明吗？

是。 选择“为会议室单独设置”以为每个临时会议室提供独特的说明。

+++

+++如何在会话期间开始临时会议室？

打开已配置的拆分配话，然后选择“开始拆分”。 参与者将被移至其分配的会议室，并可以开始协作。

+++

+++我能否加入临时会议室以协助与会者？

是的，您可以从分组讨论区控件中选择“加入”来加入会议室。

+++

+++如何在不加入分组讨论室的情况下监视讨论？

在活动的分组会话期间，选择“检查工作室”以在分组工作室中查看AI生成的讨论摘要。 摘要会随着对话进展自动更新，帮助您监控学习者讨论，评估与活动的协调程度，以及决定是否加入会议室。

+++

+++能否在临时突破会话结束后访问临时突破摘要？

是。 分会会话结束后，选择“查看报告”可查看按会议室划分的摘要、参与者详细信息、活动说明和会话信息。 专题讨论会信息板中还提供了专题讨论见解，您可以在该信息板中查看摘要并分析专题讨论会后的结果。

+++

+++如何结束临时会议室？

如果您为分机活动设置了持续时间，则当分配的时间过期时，分机会议室将自动结束，所有参与者将返回主会话会议室。 您也可以选择“结束中断”来随时结束活动。 参与者在回到主会议室之前会接受五秒钟的倒计时。

+++

+++我什么时候应该使用休息室？

当参与者需要在较小的小组中进行协作、参与讨论、完成团队活动或进行练习时，请先使用分组讨论室，然后再与较大的受众分享结果。

+++

+++分组讨论会是否可以延长到计划时间之外？

是。 讲师可以从中断控件中选择将时间延长2分钟，以延长活动中断会话。 每个分组讨论活动最多可将会话扩展两次。 会立即应用更新后的持续时间，从而使参与者可以不间断地继续讨论和活动。

+++

### 问答和人工智能辅助回复

+++如何提高AI生成答案的准确性？

在会话开始之前，请上传相关参考素材，以帮助AI生成更准确且上下文感知的响应。 在“聊天”面板中，选择“上传AI参考”，然后上传您希望AI用作参考内容的文件。

+++

+++在哪里可以查看参加者的提问？

参与者在“所有人”选项卡中发布的问题会自动收集到聊天面板的“问题”选项卡中，讲师可以在其中查看并回复这些问题。

+++

+++如何生成AI辅助回复？

打开“聊天”面板中的“问题”选项卡，将鼠标悬停在一个问题上，然后选择AI辅助回复。 查看生成的响应，进行任何必要的更改，然后选择发送。

+++

+++能否在发送AI生成的响应之前对其进行编辑？

是。 AI生成的响应是可编辑的。 您可以在发送内容之前查看和修改内容，以确保答案准确且适合您的参与者。

+++

+++为什么应上传AI参考材料？

参考资料提供更多上下文，可帮助AI生成与会话内容更相关的响应，从而减少手动回答常见问题的需要。

+++

+++AI是否自动响应学习者问题？

数字 AI会生成建议的响应以供讲师审核。 讲师决定是否编辑并向参与者发送响应。

+++

+++对于私人聊天或临时聊天室中提出的问题，AI辅助回复是否有效？

数字 AI辅助回复仅适用于在主会议室的“所有人”聊天中发布的问题和消息。 在私人聊天或临时聊天室中提出的问题不包括在人工智能支持的答案生成中。

+++

+++哪些聊天消息用于AI支持的问题分类和答案生成？

AI支持的问题分类和答案生成使用在主会议室的“所有人”聊天中发布的消息。 来自私人聊天和临时聊天的信息不会被这些AI功能处理。

+++

### 聊天和消息

+++我可以使用哪些聊天选项卡？

“聊天”面板包含以下选项卡：

* 所有人：与所有会话参与者共享消息。
* 私人：与个人参与者交换一对一消息。
* 问题：查看和管理在会话期间提交的学习者问题。

+++

+++在会话期间，我能否与学习者进行私人对话？

是。 打开“聊天”面板中的“私人”选项卡，选择参与者，输入您的消息，然后选择“发送”。 私人对话仅对参与聊天的参与者可见。

+++

### 录制会话

+++如何录制会话？

在会话期间，从控制栏中选择“更多选项” ，然后选择“录制”。 此时会显示一条确认消息，指示录制已开始。

+++

+++当我录制会话时，是否转录该会话？

是。 录制开始时，实时中心会自动开始转录会话。 此时会显示一条确认消息，指示已开始录制和转录。

+++

+++为什么要录制会话？

录制会话后，参与者和讲师可以重新访问内容。 录制对于审查讨论、强化关键概念和支持无法参加现场会话的参与者非常有用。

+++

### 共享内容

+++如何共享我的屏幕？

从控制栏中选择“共享屏幕”，选择是要共享浏览器选项卡、应用程序窗口还是整个屏幕，然后选择“共享”。 所选内容将对所有参与者可见。

+++

+++在会话期间，我可以共享哪些内容？

您可以共享浏览器选项卡、特定应用程序窗口或整个屏幕，具体取决于您要显示的内容。

+++

+++我可以注释共享内容吗？

是。 在共享屏幕时，可使用“批注”突出显示信息、将注意力吸引到关键领域以及与参与者实时协作。

+++

+++是否可以保存屏幕上显示的内容？

是。 从选项菜单中选择导出快照，以捕获和保存当前共享视图。

+++

+++我是否允许参与者共享其屏幕？

是。 如果讲师启用了“共享屏幕”权限，则参与者可以共享其屏幕。 演示时，参与者还可以使用批注工具和导出快照。

+++

+++何时应使用屏幕共享？

使用屏幕共享在实时会话期间展示幻灯片、演示应用程序、浏览网站、审阅文档或引导参与者完成任务和工作流程。

+++

### 管理与会者

+++我可以从“与会者”面板中执行哪些操作？

“与会者”面板可以帮助您在会话期间监控参与情况和管理参与者。 您可以查看与会者状态和反应、管理举手以及与与会者沟通。

+++

+++我如何查看谁出席或缺席？

“与会者”面板会显示已注册的参与者，并指示他们是否出席。 也可显示学习者的反应和举手状态。

+++

+++我可以一次将所有学习者麦克风静音吗？

是。 在“与会者”面板中，您可以为所有参与者静音麦克风，以减少背景噪声并在会话期间保持聚焦。

+++

+++我能一次把所有举起的手放下吗？

是。 “与会者”面板包括用于同时放下所有举手的选项，在问答会话后或讨论结束后非常有用。

+++

+++能否从“与会者”面板向学习者发送私人消息？

是。 如果讲师启用私人消息，您可以使用“与会者”面板开始与单个学习者进行私人对话，而不会中断其他参与者的会话。

+++

+++为什么在会话期间应使用“与会者”面板？

“与会者”面板可集中查看学习者参与情况，从而更轻松地管理交互、响应参与信号并保持会话顺利运行。

+++

### 监控会话参与情况

+++我如何看到我的参与者有多投入？

使用会话会议室顶部的“参与人参与”指示器，在整个会话中监控学习者的整体参与情况。

+++

+++参与者参与指示符表示什么？

参与指示器可帮助讲师了解会话期间的整体学习者参与情况。 参与是根据学习者活动（例如说话、参与聊天和与会话互动）来计算的。 系统会定期更新各个参与度分数，并将其汇总，以提供整体的会话参与度。

预订指示器将显示以下级别之一：

* 高（绿色）：表示学习者参与水平高。
* 中（黄色）：表示学习者参与水平适中。
* 低（红色）：表示学习者参与水平低。

系统会为每个学习者计算参与分数，并定期刷新。 全场会议的参与级别代表所有与会者的平均参与级别。 讲师不包括在计算中。 学习者分数映射如下：

* 0-30：低参与度
* 31-60：中等参与
* 61-100：高参与度

此指标可快速了解整体参与情况，并帮助讲师调整活动以提高学习者参与度。

+++

+++在哪里可以找到参与者参与指示器？

参与者参与指示器显示在会话室的顶部，允许讲师在不中断会话的情况下监视参与。

+++

+++为什么应监控参与人参与情况？

监控参与情况有助于您了解参与者参与会话的积极程度。 参与见解可以帮助您决定何时引入投票、测验和讨论等活动，以鼓励参与并保持参与者的参与。

+++

### 结束会话

+++如何为所有人结束会话？

选择“离开”，然后在确认对话框中选择“结束所有会话”。 这将结束所有参与者的会话。

+++

+++结束会话后会发生什么？

所有参与者将从会话中删除，并重定向到会话完成屏幕。 从那里，他们可以返回到课程页面。

+++

+++我应该在何时为所有人使用“结束会话”？

当培训会话结束时，如果您希望同时关闭所有参与者的会议室，请使用全部人员结束会话。

+++

### 会话录制和分析

+++会话结束后，我在哪里可以找到录制和分析？

在会话结束后，您可以从会话概述页面访问会话录制、转录文本和分析。

+++

+++如何查看会话录制？

转到“过去的会话”，选择要查看的会话，然后在“会话录制”部分中选择“查看”。 要修改录制，请选择编辑。

+++

+++如何打开会话分析？

转到“过去的会话”，选择所需的会话，然后选择会话分析URL以打开分析仪表板。

+++

+++会话分析中包含哪些信息？

会话分析可让您深入了解会话活动和学习者参与情况，包括：

* 会话摘要：查看会话详细信息和录制信息。
* 交互：查看投票、测验、分组讨论室、问答和反应活动。
* 参与者活动：在整个会话中监控学习者的参与和参与情况。
* 报告：下载会话报告和交互数据以供进一步分析。

+++

+++我可以在会话结束后查看会话成绩单吗？

是。 会议记录可与录音并存，以便您更轻松地查看讨论和重温特定主题。

+++

+++为什么应查看会话分析？

会话分析可帮助您了解参加者如何与内容交互、确定参与趋势、衡量参与度以及评估培训会话的有效性。

## Prime 中的讲师

### 课程注册

+++我可以自行注册课程吗？

是。 如果课程配置为自助注册，则您可以直接从“目录”页面进行注册。 注册后，课程即会显示在“我的学习”下。

+++

+++我如何知道我已被注册？

注册后，课程将添加到Adobe Learning Manager中的学习计划中。 您还会收到应用程序内通知。 根据您组织的通知设置，您还会收到电子邮件邀请。

+++

+++注册后可在何处找到课程？

您可以从“我的Adobe Learning Manager学习”中访问已注册的课程。

+++

### 加入会话

+++如何以学习者身份加入Live Hub会话？

登录Adobe Learning Manager并转到“我的学习”。 打开已注册的课程，选择“开始”>“转到会话”，然后选择“加入”。

+++

### 隐藏式字幕

+++如何打开隐藏式字幕？

从控制栏中选择“抄送”以打开隐藏式字幕。 再次选择抄送可将其关闭。

+++

+++为什么应使用隐藏式字幕？

隐藏字幕在会话期间将口语内容显示为文本，从而提高了辅助功能。 他们可帮助您更轻松地关注讨论，并支持您参与各种学习和倾听环境。

+++

### 在会话期间参与

+++如何尝试测验或投票？

当讲师在会话期间发布测验或投票时，它会自动出现在学习者屏幕上。 请按照屏幕上的提示根据所提供的问题类型提交您的答复。

+++

+++我可以查看投票结果吗？

可以，如果讲师在启动投票时为所有学习者启用显示结果，则您可以在会话期间查看与参与者共享的结果。

+++

+++能否查看测验结果？

可以，如果讲师在启动测试时为所有学习者启用“显示结果” ，则您可以查看在会话期间与参与者共享的结果。

+++

+++为什么应在会话期间使用聊天？

聊天可让您在不中断演示者的情况下参与讨论、提问并分享反馈，十分方便。 当麦克风访问受限，或者您希望在演示期间添加内容时，此功能特别有用。

+++

+++如何在会话期间提问？

使用“聊天”面板中的“所有人”选项卡提问、共享评论和参与讨论。 键入您的消息，然后选择发送。 在此选项卡中发布的消息对所有会话参与者可见。

+++

+++我可以在会话期间进行私人对话吗？

是。 打开“聊天”面板中的“私人”选项卡，选择参与者，输入您的消息，然后选择“发送”。 私人对话仅对参与聊天的参与者可见。

+++

+++在会话期间，如何向讲师提问？

您可以通过以下任一方式提出问题：

* 在“所有人”选项卡中发布您的问题，以便所有会话参与者均可查看。
* 如果希望您的问题仅对讲师可见，请向讲师发送私人消息。

+++

+++我何时应该使用私人聊天？

对于与整个受众无关的个人后续问题、说明或对话，请使用私人聊天。

+++

+++我可以共享屏幕吗？

是。 如果讲师启用了“共享屏幕”权限，则您可以共享屏幕。 演示时，您还可以使用注释工具和导出快照。

+++

### 临时会议室

+++能否查看我的分组讨论摘要？

是。 在分组讨论会话结束后，您可以查看您所在文件室的AI生成报告。 该报告包括检测到的活动类型以及您的组讨论的关键点的书面摘要。 选择屏幕右下角的“分接”（网格）图标，选择分接会话，然后选择“摘要”。

+++

+++我可以查看其他临时会议室或我之前所在会议室的报告吗？

数字 您只能查看您最近所在文件室的报告。 如果讲师在同一个讲座期间将您转到不同的会议室，则只会显示您最近会议室的摘要，您永远不会看到来自其他参与者会议室的报表。

+++

### 会话之后

+++我可以在会话结束后访问录制内容吗？

是。 会话结束后，您可以根据为会话配置的权限和录制设置，从课程中访问录制。 您可以直接导航到主题以查看录制的相应部分，并审阅侧重于该主题的AI生成的摘要，从而更轻松地重新访问特定讨论和关键收获，而无需观看整个录制。

+++

+++录制会话后可提供哪些其他内容？

除了录制内容之外，Live Hub还提供了会议记录，使得查看讨论和查找特定信息更为轻松。 AI生成的主题将录制内容整理到关键讨论区并包含特定主题的摘要。 主题可以跨越录音的多个非连续段，从而允许您查看该主题的所有相关时刻，而无需手动搜索整个会话。

+++

+++我可以在会话结束后提供反馈吗？

是。 在会话完成屏幕上，您可以共享有关音频和视频体验的反馈。
