# 讲师在实时中心会话中的角色

作为Adobe Learning Manager中的讲师，您在提供有效的实时中心会议和确保丰富的学习体验方面起着关键作用。

本文介绍了讲师在ALM中管理Live Hub会话的工作流程和最佳实践，包括会话前的准备、在会话期间管理互动以及会话结束后查看结果。

## Live Hub会话的讲师工作流

### 在会话前准备

在计划的开始时间之前，使用会话URL加入Live Hub会议室，以便在学习者加入之前进行设置。 有关详细信息，请查看[加入会话](./join-live-hub-session-as-an-instructor.md)。

在房间内，您可以：

* 配置学习者权限，例如启用屏幕共享和白板访问。 查看[以讲师身份管理会议室设置](./manage-settings.md)以了解更多信息。

* 使用AI生成的破冰机或您自己的问题提前创建投票。 查看[创建并启动投票](./create-and-launch-a-poll.md#create-a-poll-using-ai)以了解更多信息。

* 为参与和评估构建测验（多选或多答）。 查看[创建和管理测验](./create-and-manage-a-quiz.md#create-a-quiz)，了解更多信息。

* 设置Miro以启用实时协作和集思广益。 查看[共享白板](./share-a-whiteboard.md#share-miro-and-other-external-whiteboards)以了解更多信息。

* 设计分组讨论区、指定学习者并为每个会议室添加说明。 查看[创建和管理临时会议室](./create-and-manage-breakout-rooms.md#design-a-breakout-session)，了解更多信息。

* 上传参考资料，以便AI能够在会话期间为学习者问题生成准确、可感知上下文的答案。 查看[以讲师身份使用聊天面板](./use-the-chat-panel-as-an-instructor.md#upload-files-for-better-responses)，了解更多信息。

### 管理会话

在会话期间，专注于有效地提供内容，同时保持学习者的参与度。 您可以：

* 启动并管理实时会话。

* 录制会话，以便可以稍后回放和查看。 有关详细信息，请查看[录制会话](./record-a-session.md)。

* 使用可用的参与工具（如共享、聊天、问答等）展示内容。

* 共享屏幕、添加批注以突出显示信息以及导出快照。 有关详细信息，请查看[共享屏幕](./share-your-screen-as-an-instructor.md)。

* 启动准备好的投票和测验，并选择是否向学习者显示结果。 查看[创建和管理测验](./create-and-manage-a-quiz.md)，了解更多信息。

* 通过聊天、投票和讨论启用学习者互动。

* 使用参与指示器（“高”、“中”或“低”）监控参与人参与情况，并跟踪出席情况。 查看[跟踪参与者参与](./track-the-participant-engagement.md)以了解更多信息。

* 管理音频和视频权限。

### 管理学习者互动

确保在整个会话中顺畅地进行沟通和协作。 您可以：

* 使用“聊天”面板和问答功能回复问题，包括“问题”选项卡中的AI辅助回复。 查看[以讲师身份使用聊天面板](./use-the-chat-panel-as-an-instructor.md#draft-replies-to-participant-questions-with-ai)，了解更多信息。

* 与“所有人”选项卡中的所有参与者进行互动，或者在“私人”选项卡中举行直接对话。

* 根据需要启用或限制学习者权限。

* 在“与会者”面板视图中管理出席或缺席的学习者，监控举手和反应，发送私人消息、静音麦克风和下举手。 查看[管理“与会者”面板](./manage-the-attendees-panel.md)以了解更多信息。

* 促进讨论和分组活动，包括启动临时会议室和在学习者寻求帮助时加入会议室。

* 在会话期间处理中断或技术问题。 有关详细信息，请查看[实时中心故障排除指南](../kb/troubleshooting-guide-for-live-hub.md#connection-issues)。

### 结束会议

培训完成后，结束所有参与者的课程。 在会议结束后，查看会议概述页面上的结果：

* 访问会话录制和转录文本，并根据需要编辑录制内容。 有关详细信息，请查看[录制会话](./record-a-session.md#view-topics-in-recording)。

* 查看会话分析，包括会话摘要；投票、测验、分组讨论、问答和反应等交互；参与者活动；以及可下载的报告。 有关详细信息，请查看[会话仪表板](./view-the-session-dashboard.md)。
