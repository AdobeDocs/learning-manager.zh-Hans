# 系统要求

使用以下系统要求在Adobe Learning Manager中配置和运行Live Hub会话。 实时中心与运行它的虚拟教室环境使用相同的浏览器、操作系统和硬件要求。

Live Hub在虚拟教室会话中提供，不需要单独的客户端安装。

| 类别 | 要求 |
|---|---|
| **桌面浏览器** | Google Chrome、Mozilla Firefox、Microsoft Edge和Safari的最新版本 |
| **移动浏览器** | Chrome Mobile、Safari Mobile和Samsung Internet |
| **操作系统** | Windows 10或更高版本、macOS 15或更高版本 |
| **屏幕分辨率** | 1920 × 1080、1366 × 768、768 × 1024（平板电脑）和375 × 667（移动版） |
| **Windows硬件** | 最低8 GB RAM，8核处理器，Intel® Core™ i5或更高版本 |
| **Mac硬件** | 最低16 GB RAM，四核处理器，3.2 GHz或更高 |
| **网络** | 稳定的宽带连接，建议实时音频、视频和AI支持的实时集线器功能使用至少5 Mbps |

>[!NOTE]
>
>不支持Linux浏览器、Chromebook设备、Firefox移动版、Opera（桌面和移动版）、Internet Explorer 11及更早的浏览器版本。
