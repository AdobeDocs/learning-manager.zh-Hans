# 跟踪参与人参与情况

通过实时网络中心中的参与者参与功能，讲师可以在实时会话期间实时查看学习者参与情况。 它将浏览重点、聊天活动和投票参与情况合并为单个参与级别，显示为绿色、黄色或红色指示器。 使用它可以发现注意力下降并实时调整投递情况。

参与者参与显示了在指定时间点，主会议室中所有学习者的平均参与级别。 级别会在学习者加入会话后立即刷新。

参与人参与仅在实时会话期间计算和显示。

>[!NOTE]
>
> 只有讲师才能看到订婚表。 学习者无权访问。

## 了解参与级别计算

您可以在实时中心会话界面的右上角查看参与级别。 它显示为学习者参与情况的实时指示器。

![参与级别指示器](assets/engagement-level-indicator.png)
*在右上角显示参与者参与的Live Hub界面。*

系统使用以下三个因素计算参与级别：

* **浏览器焦点**：学习者屏幕上的“虚拟教室”选项卡或窗口是否处于活动状态。

* **聊天活动**：学习者通过会话聊天中的消息参与。

* **投票参与率**：在会话期间对投票提交的响应。

## 确定参与级别和指标

参与人参与方式会根据学习者互动情况使用颜色编码的指示器。 每个级别的含义如下：

| **参与级别** | **颜色指示器** | **描述** |
|----|----|----|
| 高 | 绿色 | 学习者可积极参与课程。 |
| 中等 | 黄色 | 学习者偶尔与中度参与者互动。 |
| 低 | 红色 | 学习者在会话期间很少互动或没有互动，或者焦点减少。 |
