# 跟踪参与者的参与情况

通过实时中心中的参与者参与，讲师可以在实时会话期间实时查看学习者或参与者参与情况。 它将浏览重点、聊天活动和投票参与情况合并为单个参与级别，显示为绿色、黄色或红色指示器。 使用它可以发现注意力下降并实时调整投递情况。

参与者参与显示了在指定时间点，主会议室中所有学习者的平均参与级别。 级别会在学习者加入会话后立即刷新。

参与人参与仅在实时会话期间计算和显示。

>[!NOTE]
>
> 只有讲师才能看到参与者的参与情况。 学习者无权访问。

## 了解参与级别计算

参与者的参与度分数能帮助您在实时会话期间实时监控学习者的参与度。 屏幕顶部的此参与徽章将整体参与级别显示为&#x200B;**低**、**中**&#x200B;或&#x200B;**高**，允许您调整会话传递并根据需要鼓励参与。

该指示器仅对主会议室中的讲师可见。

## 参与分数是如何计算的

每个学习者或参与者的参与得分范围为0到100，具体取决于以下因素：

- **注意会话**：当学习者或参与者保持会话窗口活动时，默认情况下，他们的参与级别为高。 如果他们切换到其他窗口或浏览器选项卡，除非继续参与会话活动，否则参与级别将降至“低”。
- **参与会话**：在会话中发言、共享屏幕、发送聊天消息、回复投票或测验、画白板、举手、发送反应和单击等活动可提高参与分数。

### 参与分数的变化

学习者根据关注度和参与度，在整个实时会话中对其参与度进行评分。 以下条件会影响参与分数的计算方式：

- **活动持续时间**：大多数参与活动会暂时增加参与分数，其贡献会在大约5分钟内逐渐降低。 例如，如果学习者在会话期间发言，然后切换到另一个窗口，则其参与分数会逐渐降低，而不是立即降低
- **屏幕共享**：在学习者或参与者共享其屏幕时，参与分数保持为100。
- **同时活动**：当学习者或参与者同时执行多个活动时，仅考虑具有最高参与值的活动。 单个活动中的分数不会合并，确保参与分数不超过100。
- **多个设备**：如果学习者或参与者从多个设备加入会话，则会考虑这些设备中的最高参与分数。

## 总体参与分数

参与者参与徽章根据主会议室中所有学习者的平均参与得分显示整体参与级别，并舍入到最接近的整数。

在计算总体参与得分时，以下条件适用：
- **讲师和录制机器人**：讲师和录制机器人不包括在整体参与分数计算中。 录制机器人未显示在与会者列表中。
- **临时会议室**：临时会议室的学习者或参与者不包括在整体参与分数中。 当学习者在主会议室和临时会议室之间移动时，他们的个人参与分数会重置，并在1到2分钟内重新计算。
- **新学习者**：参与者参与分数在加入会话约一分钟后变为可用分数。 在评分可用之前，学习者或参与者不会参与总参与分数的计算。
- **主会议室为空**：当主会议室中没有学习者或参与者时，徽章将显示没有参与级别的“参与者”参与。

## 确定参与级别和指标

参与者参与徽章根据整体参与得分显示以下参与级别之一。 您可以使用这些级别来监控学习者的关注度并根据需要调整会话的交付方式。  每个级别的含义如下：

| **参与级别** | **分数** | **描述** |
|----|----|----|
| 高 | 61 - 100 | 学习者可积极参与课程。 |
| 中等 | 31 - 60 | 学习者偶尔与中度参与者互动。 |
| 低 | 0到30 | 学习者在会话期间很少互动或没有互动，或者焦点减少。 |

>[!NOTE]
>
> - 参与分数表示会话期间的参与者关注。 它不衡量学习结果或绩效。
> 
> - 参与分数每分钟计算一次。 更改最多可能需要两分钟才能显示在参与徽章中。

## 常见问题解答

+++ 参与分数是否检测参与者是否正在积极监视会话？

数字 参与分数基于会话窗口是否处于活动状态以及参与者的活动（如说话、发送聊天消息和响应投票）来计算。 它不使用相机视频、眼睛跟踪或麦克风静音状态来衡量参与情况。

+++

+++ 当参与者从会话窗口切换开后会发生什么？

当参与者切换到其他浏览器选项卡、窗口或应用程序时，会话窗口不再被视为活动状态。 即使会话窗口仍然可见，当另一个窗口成为焦点时，它也会被视为非活动状态。

+++

+++ 是否所有参与活动都会对参与得分做出相同的贡献？

讲话、屏幕共享、发送聊天消息、回复投票或测验、画白板、举手和发送反应对参与度得分的贡献相同。 在会话中单击的贡献略低。

+++

+++ 参与活动后，参与分数如何变化？

大多数参与活动的贡献在大约5分钟内逐渐减少。 例如，如果参与者切换到另一个窗口然后发言，则在下次更新时，他们的参与得分会增加到100。 在接下来的分钟内，分数逐渐降低至80、60、40和20，在此期间会一直保持，直到参与者返回到会话窗口或再次参与为止。

使会话窗口保持活动状态的参与者会保持高参与级别。

+++

+++ 总体参与得分中是否包括临时会议室的参与者？

数字 总体参与得分的计算只包括主会议室中的参与者。 当讲师在临时会议室时，不会显示接合徽章。

+++

+++ 为什么在临时会议室结束后总体参与得分会下降？

当参与者从休息室移动到主房间时，他们的个人参与分数会重置，并在1到2分钟内重新计算。 这样可以暂时降低总体参与分数。

+++

+++ 当参与者从多个设备加入时，参与分数是如何计算的？

如果参与者从多个设备加入会话，则会考虑这些设备的最高参与分数。 一个设备上的非活动会话不会降低另一个活动设备上记录的参与分数。

+++

+++ 为什么更新订婚徽章最多需要两分钟？

每个参与者的参与得分每分钟计算一次。 然后，每分钟更新一次总体参与分数，因此更改最多可能需要两分钟才能显示在参与徽章中。

+++

+++ 当参与徽章显示为“低”时，讲师可以做些什么？

参与度低表示大多数参加者已离开会话窗口，未积极参与。 讲师可使用投票、测验、聊天提示或讨论问题来鼓励参与以及将参与者的注意力吸引回会话。

+++

+++ 讲师能否使用参与度分数来跟踪出勤情况或评估学习者？

参与得分提供了参与者在会话期间的注意力和活动的一般指示。 参与人可以通过保持会话窗口处于活动状态来保持高参与级别，即使没有积极参与或演示学习也是如此。 因此，参与得分可能不适合评估学习者表现或跟踪出勤情况。

+++

+++ 参与者可以查看其参与度分数吗？

数字 只有讲师可以看到订婚徽章。

+++

+++ 讲师能否查看单个参与者的参与分数？

数字 预订徽章仅显示主会议室的总预订分数。 单个参与人分数不可用。

+++

+++ 讲师能否禁用参与跟踪？

数字 参与跟踪始终处于启用状态，且无法禁用。

+++

+++ 在报告或答疑历史记录中是否提供了参与分数？

数字 参与徽章仅显示当前的整体参与分数。 参与得分不会保存或包含在报告或会话历史记录中。

+++

+++ 共同讲师能否查看参与徽章？

是。 讲师还可以在会话期间查看参与徽章。

+++

+++ 如何在移动设备上计算参与分数？

参与者可以通过移动浏览器访问实时中心会话。 使用与桌面浏览器相同的标准计算参与分数。

+++
