# 了解录制内容和转录文本

在实时中心录制会话后，学习者可以重新访问会话，讲师可以在实时会话之外继续学习。 每段录音都捕捉到了核心课堂体验，并通过AI支持的功能对其进行增强，以支持轻松的导航和内容发现。

会话结束后，录制内容会自动进行处理并在课程页面上提供，通常在几分钟内即可完成。 除视频外，系统还会生成基于AI的主题、摘要和转录，使学习者无需观看整个录制即可快速查找和审阅相关部分。

## 主要优点

* **结构化和交互式播放**：使用AI生成的主题导航录制，而不是线性观看。 快速跳到关键讨论点，只查看重要的内容。

* **通过转录文本和见解增强学习**：关注时间同步转录文本，并利用AI生成的摘要和主题更好地了解会话内容。

* **灵活的录制配置**：根据您的会话要求，控制录制中捕获的内容，如学习者视频、投票和聊天。
