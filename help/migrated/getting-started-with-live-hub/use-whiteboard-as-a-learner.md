# 以学习者身份使用白板

白板在Live Hub会话期间提供共享的可视化工作区。 当讲师启用白板访问时，您可以在共享画布上绘制、添加形状和文本以及擦除内容。 使用白板演示创意、解决问题并参与实时协作活动。

本文介绍了如何在Live Hub中以学习者身份使用白板。

## 使用白板

当讲师允许学习者编辑白板时，您可以在实时会话期间与白板进行互动。 在会话中，您可以：

* 使用标记工具在白板上绘制。

* 添加形状和文本以创建或添加内容。

* 从白板擦除绘图、形状或对象。
