# 查看会话信息板

Live Hub中的会话信息板提供了有关学习者参与、参与和会话表现的见解。 它可帮助讲师回顾学习者在会话期间如何互动并评估其效果。

信息板整合了出席、参与和互动等关键指标，为将来的会议提供了更好的分析和决策。

## 主要优点

* **集中式可见性**：从单个仪表板监视学习者参与、出席和交互。

* **参与见解**：了解学习者在会话期间如何进行交互并确定参与模式。

* **性能分析**：使用参与和交互数据评估会话效果。

* **数据驱动改进**：使用信息板中的见解来增强未来的会话和学习结果。

## 访问“会话”信息板

请按照以下步骤查看Live Hub会话的会话信息板：

1. 以讲师身份登录Adobe Learning Manager。

1. 从&#x200B;**您的会话**&#x200B;中选择&#x200B;**过去的会话**。 这将打开&#x200B;**您过去的会话**&#x200B;页面。

   ![过去的会话导航](assets/past-sessions-navigation.png)
   *从“您的会话”中选择“过去的会话”以打开“过去的会话”页面。*

1. 打开要检查其会话分析的课程。<br> 此时会显示&#x200B;**会话概述**&#x200B;页面。

1. 导航到&#x200B;**实时中心**&#x200B;部分，然后选择&#x200B;**查看分析页面**。<br> 将打开&#x200B;**分析**&#x200B;仪表板，其中包含所选会话的详细见解。

   ![会话分析Url选项](assets/session-overview-page.png)
   *在“实时中心”部分中选择“查看分析”页面以打开“分析”仪表板。*

## 有哪些深入见解

会话信息板通过多个选项卡显示会话数据，每个选项卡侧重于学习者参与和绩效的特定方面。 这些视图共同帮助讲师分析会话的出勤情况、参与级别和交互模式。

![会话仪表板见解概述](assets/session-dashboard-insights-overview.png)
*会话仪表板会显示“会话摘要”、“交互”、“参与者活动”和“报告”选项卡中的数据。*

会话操控板中提供以下选项卡：

| **制表符** | **描述** |
|----|----|
| **会话摘要** | 提供实时和录制表演的高级概述，包括会话持续时间、注册和加入的学习者数量、平均出席持续时间、一段时间的出席情况、参与者参与以及录制见解（例如总查看次数和平均查看持续时间）。 |
| **交互** | 按交互方法显示参与者的参与情况，并将其组织为投票、测验、分组和其他交互，从而能够分析学习者如何参与交互活动。 |
| **参与者活动** | 提供针对参与者的详细信息（包括出席和互动数据），以帮助跟踪个人参与情况。 |
| **报告** | 允许您下载会话分析和数据以供离线审阅。 |

有关详细信息，请查看[会话仪表板](./components-of-the-session-dashboard.md)的组件。
