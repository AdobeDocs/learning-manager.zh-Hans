# Adobe Learning Manager中的LTI深度链接

## 概述

**以下部分适用于管理员**

LTI深度链接是一项LTI优势功能，讲师或课程作者可从中浏览、选择特定学习项目并将其直接嵌入到外部LTI工具消费者/平台（如Canvas或Moodle）课程中。

LTI深层链接简化了将课程添加到学习平台（如Moodle）的过程。 在当前工作流程中，作者必须手动复制课程URL（包括导出UUID参数），然后在配置课程链接时将所需详细信息粘贴到LMS中。 每个课程和每个位置都必须重复此步骤。 例如，如果需要在10个不同的位置添加相同的课程，作者必须重复10次复制和粘贴过程。 这种手动方法会增加工作量，并带来更高的配置错误风险。

深层链接允许LMS在设置期间处理课程选择，从而消除了此类开销，并为内容选择提供了适当的启动URL。

在此模型中：

* 外部LMS中的讲师和作者可启动专用的深层链接选择体验来浏览ALM。
* 系统会将深度链接对象从ALM返回到外部LMS，以便所选项目可以嵌入到其课程创作工作流程中。
* 学生在其主要LMS中使用深度链接内容，这些内容可无缝地启动在ALM中托管的材料。

## 问题陈述

ALM目前支持LTI 1.3集成，但没有完整的深层链接工作流程，因此讲师和作者没有结构化的方法能够：

* 从模式中启动专用的深层链接选择体验。
* 仅浏览给定平台应显示的学习对象。
* 从平台中选择特定学习对象。
* ALM将该学习对象返回给平台，以便可以直接嵌入到课程中。

没有此功能：

* 内容选择是手动进行的，或者内容是分散的
* 除非明确过滤，否则所有帐户内容都可能会无意中暴露
* 工具提供商集成更难操作
* 课程作者无法使用一致且受管的工作流程嵌入外部LTI内容

## 目标

此功能的主要目标是：

1. 在LTI工具提供商中启用LTI深度链接
   * 支持从ALM到LTI工具提供商的深层链接启动。
2. 提供受监管的内容选择工作流程
   * 在深度链接选择期间仅公开已批准和相关目录及内容。
3. 允许讲师和作者选择学习对象
   * 提供一个可搜索且可筛选的UI用于选择符合条件的学习对象。
4. 将有效的深层链接响应返回到ALM
   * 使用具有所需深层链接负载的deep_link_return_url参数将用户重定向回平台。
5. 支持平台特定的目录公开
   * 允许管理员控制向哪个LTI平台公开哪些目录。

## 角色及其角色

LTI深度链接工作流程涉及以下角色：

| 角色 | 描述 |
|---|---|
| 讲师或作者 | 创建或管理课程并启动深层链接选择流以嵌入外部内容。 |
| 集成管理员 | 注册和管理LTI工具，并启用和配置深层链接行为。 |
| Prime 中的讲师 | 启动和使用通过深层链接工作流程添加的内容。 |

*从配置到使用，每个角色都映射到深层链接工作流程中的不同步骤。*

## 数据和参数要求

深度链接在ALM和LTI平台之间交换以下参数：

| 参数 | 目的 |
|---|---|
| `deep_link_return_url` | 用于向ALM发送回所选深层链接对象的返回终结点 |
| `accepted_types` | 定义平台接受的资源类型 |
| `accept_multiple` | 指示是否允许多个资源选择；每个工具均可配置 |
| `auto_create` | 指示平台可以自动创建链接的资源条目 |

*这些参数控制公开哪些内容以及将选择内容返回到ALM的方式。*

## 创建深层链接

### 先决条件

1. 您应该以集成管理员身份登录。
2. 设置LTI集成时，选中支持深度链接复选框。
3. 在字段中提供URL以使用户或作者进入所选内容。
4. 选择保存更改。

   同一启动URL可重复用于简化配置和使用。

   该行为由LTI消息类型决定。 当消息类型为`content_consumption`时，用户将被定向到课程播放器。 当消息类型为`content_selection`时，用户将通过深层链接流程进行路由，作者可以直接选择所需的内容，而无需手动复制课程特定的标识符。

   保存更改后，选择&#x200B;**选择内容**&#x200B;选项卡。 （只有在选中此复选框后，**选择内容**&#x200B;选项卡才会变为活动状态。）

**以下部分适用于作者。**

作者可以从&#x200B;**选择内容**&#x200B;窗口中选择内容。 **选择内容**&#x200B;窗口显示&#x200B;**目录**、**课程计数**&#x200B;和&#x200B;**导出日期**。

1. 转到外部集成工具。

   ![](assets/image_0005.png)

2. 选择&#x200B;**目录**，并通过选中每个课程旁的复选框来选择要深层链接的课程。 如果添加多个课程，则会弹出确认弹出窗口，要求您进行确认。

   ![](assets/image_0002.png)

   ![](assets/image_0003.png)

3. 选择&#x200B;**添加内容**。 选择&#x200B;**添加内容**&#x200B;将填充所有字段。 您可以在“自定义参数”字段中查看导出UUID。 如果您在上一步中选择了多个课程，则会显示一条确认消息。

   ![](assets/image_0004.png)

4. 此时，如果您想要选择其他课程或进行更改，可以选择&#x200B;**取消**&#x200B;并返回&#x200B;**选择内容**&#x200B;选项卡，或者可以选择&#x200B;**保存并返回**&#x200B;课程或选择&#x200B;**保存并显示**。 深层链接会添加到目标中。

   ![](assets/image_0001.png)
