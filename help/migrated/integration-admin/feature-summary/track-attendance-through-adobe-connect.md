# 通过Adobe Connect录制视图跟踪出席情况

## 概述

Adobe Learning Manager可以通过记录观看次数来跟踪Adobe Connect虚拟教室授课的出席情况。 如果学习者错过了实时会话，但在Adobe Connect上观看录制足够长时间，Learning Manager会将学习者标记为已参加会话。 然后，学习者完成会话模块，并可继续完成会话所属的学习对象。

使用此功能之前，Learning Manager无法记录观看Connect录制的学习者的出席情况。 错过实时会话的学习者无法完成该会话，因此讲师必须介入并手动标记出勤情况。 此功能将删除该手动步骤。 Adobe Connect会报告观看了哪个录像和时长，而Learning Manager会将观看时间与为帐户设置的完成标准进行比较。

当学习者符合录制的会话的完成条件时，系统就会在管理员应用程序中标记该学习者。

学习者电子邮件ID在Adobe Learning Manager和Adobe Connect中应相同，因为Adobe Learning Manager会使用相同的电子邮件ID将学习者重定向到Adobe Connect。
集成管理员可以设置的默认同步频率和最短间隔为一小时。


## 谁做些什么

| 角色 | 他们执行的操作 |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------|
| Prime 中的讲师 | 打开会话录制，并在缺少实时会话后观看录制。 |
| 讲师 | 在实时会话期间开始录制，以便存在录音和转录。 |
| 集成管理员 | 配置出勤同步使用的Adobe Connect帐户，并设置同步计划或将其打开或关闭。 |
| 作者或交付经理 | 安排虚拟教室授课，对于多天课程，重复使用多天的长期教室。 |
| Adobe Connect | 捕获每个学习者的电子邮件和录制观看时间，并通过API公开录制观看者的列表。 |

每个角色在进行基于录制的出勤工作时，都有单独的部分。

## 术语表

| 术语 | 含义 |
|---------------------------------|--------------------------------------------------------------------------------------------------------|
| 虚拟教室会话 | Adobe Connect上托管的虚拟教室会话。 |
| 虚拟讲师指导培训 | 讲师通过虚拟教室授课提供的培训。 |
| 学习对象 | 例如，包含会话模块的课程。 |
| 长期会议室 | 可重复用于多次会话的Adobe Connect会议室，例如第1天、第2天和第3天。 |
| 完成标准 | 学习者必须观看的录音百分比才能将其标记为模块完成。 |

## 用例

### 学习者错过了实时会话

学习者无法加入实时虚拟教室会话。 稍后，学习者即可在Learning Manager中打开会话并观看录制。 一旦观看时间满足完成标准，Learning Manager会将学习者标记为已参加，学习者无需向讲师寻求帮助即可完成模块。

### 只看部分内容的学习者

学习者打开录制，但观看的共享内容少于要求的共享内容。 未满足完成标准，因此Learning Manager不会将学习者标记为已参加。

### 在一间长期教室中进行多天会话

作者或交付经理在同一持续Connect会议室安排第1天、第2天和第3天的会议。 他们无需登录Adobe Connect即可查看和重复使用会议室名称。

## 主要功能

| 特色 | 功能 |
|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| 自动出勤 | 当学习者观看录制的长度足以满足规定的阈值限制时，将学习者标记为已参加基于Connect的虚拟教室会话。 |
| 观看连接 | 使用Adobe Connect捕获的学习者电子邮件和录制观看时间。 |
| 完成标准阈值 | 当观看时间达到完成标准中设置的百分比时，将学习者标记为模块已完成。 |
| 仅实际监视时间 | 计算学习者真正观看的时间。 拖动搜索栏不会增加监视时间。 |
| 计划同步 | 按照集成管理员控制的计划运行后端管道，并且可以打开或关闭。 |
| 持续查看文件室 | 在实例级别显示Connect会议室名称，以便作者可以跨天重复使用长期会议室。 |

## 出勤情况跟踪工作方式

*如果学习者打开录音，则进入Learning Manager，表明模块已完成。*

### 端到端流

1. 讲师在Adobe Connect上主持实时虚拟教室会话并开始录制。 会话结束后，录音和转录文本将变为可用。

1. 错过会话的学习者可以选择查看录音。 Adobe Connect会自动跟踪视图。

1. Adobe Connect会捕捉学习者的电子邮件以及实际花费在观看上的时间。

1. 按照配置的时间表，后端SnapLogic管道将调用Adobe Connect API，并提取给定时间帧的录制查看器的列表。 管道使用在集成管理员中设置的Adobe Connect帐户。

1. Learning Manager会将每个查看器映射到匹配的课程和模块。

1. Learning Manager会将学习者的总观看时间与完成条件进行比较。

1. 如果观看时间符合标准，Learning Manager会将学习者标记为模块已完成。 在后端，Learning Manager会通过填充用户课程等级CSV来记录这种情况。

>[!NOTE]
>
>Adobe Connect不会将数据推送到Learning Manager。 Learning Manager会将其拖放到Adobe Connect实例级别，例如“这五名用户在过去24小时内观看了这六段录音。” 因此，出勤情况在下一次管道运行后更新，而不是学习者完成观看的那一刻。

### 完成标准和观看时间

学习者必须至少观看完成标准定义的录制百分比。 请牢记这些规则：

* 该百分比适用于录制持续时间，而不是计划会话持续时间。 如果只录制了5分钟的15分钟会话，则所需时间基于5分钟。 Adobe Connect会提供录制持续时间。

* 百分比在Learning Manager端设置。 这是帐户中的通用设置，不是每个实例的设置。 已应用于实时会话的相同类型的设置，例如需要80%的参与率。

* Adobe Connect会记录学习者实际观看的时间。 不计入搜寻栏，Learning Manager会处理Connect通过前的观看时间。

| 完成标准 | 录制长度 | 所需观看时间 | 结果 |
|-------------------------|------------------------------------|-----------------------|-------------------------------------------------------------|
| 50% | 5分钟 | 2.5分钟 | 观看后2.5分钟，将标记为完成。 |
| 50% | 5分钟（会话时长为15分钟） | 2.5分钟 | 基于5分钟的录音，而不是15分钟的录音。 |
| 0% | 任何 | 除打开之外没有其他内容 | 打开录音就足够了。 |

### 资格窗口

Learning Manager仅在学习对象完成日期之前应用基于录制的出勤情况。 如果学习对象没有完成日期，Learning Manager将使用父学习对象的完成日期。

### 安排同步

集成管理员控制管道运行的频率。 该计划可以为每小时或每周，也可以为其他时间间隔，集成管理员可以打开或关闭该计划。 每次运行都使用相同的Adobe Connect帐户。

### 更改内容

* 用户添加第1天创建的长期教室时，Learning Manager会授予其访问该教室的权限。 然后，他们可以在其他日子将同一个会议室添加到会议中。
* Learning Manager在&#x200B;**虚拟教室URL**&#x200B;旁边的会话详细信息中显示实例级别的Connect会议室名称。
* 对于默认实例，Learning Manager会显示课程创建期间设置的会议室。

### 限制和注意事项

* 出勤不是实时的，因为Learning Manager会按计划提取数据。
* 此功能仅涵盖基于Connect的虚拟教室会话。
* 录音必须存在，因此讲师必须在实时会话期间开始录制。
* 学习者可通过Adobe Connect捕获的电子邮件地址进行匹配。
* 拖动搜索栏不会增加监视时间。
* 基于录制的出勤将在学习对象或父学习对象的完成日期停止。

### 注意事项

* 观看时间必须大于或等于规定的百分比（例如，5分钟的50%是2.5分钟）。 如果学习者重复观看会话，但还未达到规定的观看时间，观看时间不会增加。 但是，即使学习者在不同的时间点按部分查看会话并符合阈值标准，查看时间也会增加。 例如，如果学习者在第1天观看一分钟的会话，然后在第二天从离开点开始观看另外1.5分钟的会话，则观看时间会增加。 这发生在Adobe Connect一侧。

* 可以在课程级别和帐户级别配置完成标准。 其效果与实时会话参与效果相同。

* 集成管理员可以设置的默认同步频率和最短间隔为一小时。

* 学习者电子邮件ID在Adobe Learning Manager和Adobe Connect中应相同，因为Adobe Learning Manager会使用相同的电子邮件ID将学习者重定向到Adobe Connect。

### 常见问题解答

**问：学习者是否必须参加实时会话？**
**A.**&#x200B;否。 如果学习者错过了实时会话，系统仍会将其标记为已观看。

**问：学习者必须观看多少段录音？**
**A.**&#x200B;完成条件中的百分比应用于录制持续时间。 例如，50%的5分钟录制需要至少2.5分钟的观看时间。

**问：是否跳过录制计数？**
**A.**&#x200B;否。 Adobe Connect会记录学习者实际观看的时间，因此拖动搜索栏不算。

**问：学习者完成观看后是否即会标记出勤情况？**
**A.**&#x200B;否。 Learning Manager会按计划从Adobe Connect提取查看者数据，以便在下次管道运行后更新出席情况。

**问：Adobe Connect是否会将数据发送到Learning Manager？**
**A.**&#x200B;否。 Learning Manager会将其提取。 它是Adobe Connect实例级别的拉出机制，而不是推送。

**问：Learning Manager如何知道观看了哪个学习者？**
**A.** Adobe Connect会捕获学习者的电子邮件和录制观看时间。 Learning Manager会将其映射到课程和模块。

**问：谁控制同步运行的频率？**
**A.**&#x200B;集成管理员设置计划，可以打开或关闭它。

**问：是否为每个实例设置了完成百分比？**
**A.**&#x200B;否。 这是整个帐户通用的设置。

**问：多天会话是否可以共享一个Connect会议室？**
**A.**&#x200B;是。 作者可以在其他日子重复使用为第1天创建的长期会议室，该会议室名称会显示在Learning Manager的实例层级。
