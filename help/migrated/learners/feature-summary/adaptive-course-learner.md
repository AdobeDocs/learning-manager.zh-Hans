# 适合学习者的自适应课程

## 简介

Adobe Learning Manager中的自适应课程是管理员启用此功能后，根据学习要求计算并自定义学习要求，从而由作者为您规定的课程。 有关更多信息，请参阅[自适应课程](/help/migrated/administrators/feature-summary/adaptive-course-admin.md)。

## 学习者参加自适应课程

在Adobe Learning Manager中参加自适应课程时，您会看到基于您所属用户组的个性化模块集。

### 打开自适应课程时显示的内容

打开自适应课程时，您只能看到与您相关的模块。 分配给其他用户组的模块对您完全不可见。

完成进度条和“Y个模块中的X个模块已完成”计数仅反映所需的模块。 您注册了同一课程的同事看到的模块数量可能会有所不同，必修和选修课程也可能会有所不同，或者内容设置可能会完全不同，具体取决于其用户组。

### 注册自适应课程

注册自适应课程与注册任何课程的方式相同。 您可以从目录自行注册，也可以由管理员为您注册。

![](assets/image_0010.png)

如果根据当前用户组，课程中没有可见的模块，则无法注册。 如果发生这种情况，请联系您的管理员。 这可能意味着需要更新您的用户组分配。

### 在播放器中导航模块

打开课程播放器后，左侧的目录只显示您可以看到的模块。 您可以使用导航按钮按顺序浏览模块（对于有序课程）或访问任何模块（对于无序课程）。

目录中未显示属于其他学习者用户组的模块。

### 了解您的完成要求

当您完成所有标记为&#x200B;**必修**&#x200B;的模块后，您的课程即告完成。 可选模块不会阻止您的完成。 您可以完成它们、重新访问它们或完全跳过它们，而不会影响完成进度。

### 如果教室或虚拟教室会话已满，会发生什么情况

如果对您可见教室或虚拟教室模块，但没有剩余名额，则表示您注册了该课程，并将进入该特定会话的轮候表。 您仍然可以立即访问并完成所有其他模块。 仅整个会话处于暂停状态。

当您在会话中轮候时：

* 课程播放器中会显示该会话，但您无法启动或访问它。
* 您的整体课程进度会在其他模块中正常继续。
* 当有可用名额时，您会收到通知，并且您被移出轮候表。

在您分配了名额后，会话便可供访问，您可以加入或完成会话。

### 当您的配置文件在课程中途更改时会发生什么

自适应课程体验与用户组密切相关。 如果在注册时您的用户组发生变化（例如，由于您的角色或位置发生变化），则模块会自动更新。

* 如果您更新的用户组使之前隐藏的模块对您可见，则这些模块会显示在您的课程中。 如果您的新配置文件需要这些模板，则它们会被添加到您的完成要求中。
* 如果更新的用户组不再包含模块，则会从视图中将其删除。 如果该模块以前是必需的，但现在不再需要，则会将其从完成计数中移除。
* 您已完成的任何模块仍会标记为完成，即使您的用户组发生更改也是如此。 除非先前未完成新可见的模块，否则不需要重做已完成的工作。
* 配置文件更改期间，您的开始日期、已完成模块的完成日期和整体进度记录保持不变。

### 完成课程后会发生什么

完成所有必需的模块后，课程即标记为完成。 此时，您将收到任何适用的徽章或游戏点数。

完成后，如果您的用户组发生更改并且有新的必需模块可供使用，则您的完成可能会被回滚，您可能需要完成这些附加模块。

发生这种情况时：

* 您的原始完成情况仍作为历史记录保留在您的成绩单中。
* 课程会以“进行中”状态重新打开，只显示新的必需工作。
* 您只需完成新需要的模块。
* 当触发刷新完成时，您会收到通知。
