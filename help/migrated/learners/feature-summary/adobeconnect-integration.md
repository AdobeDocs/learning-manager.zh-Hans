# Adobe Connect 集成

作为学习者，如果您的公司集成了 Adobe Connect 与 Adobe Learning Manager 帐户，那么您就可以借助 Adobe Connect 来使用虚拟教室课程。 如果您无法使用 Adobe Connect，请联系公司的管理员。

## 使用 Adobe Connect 虚拟教室课程 {#consumeadobeconnectvirtualclassroomcourses}

以学习者身份登录 Adobe Learning Manager，并在“我的学习”小组件内单击虚拟教室课程卡。 或者，可以从左侧窗格中选择“目录”，过滤课程，并单击所需的虚拟教室课程。

如果您已经注册了 Adobe Connect 虚拟教室会话，那么就会在会话开始前先收到帐户 URL 的通知。

1. 单击 URL，然后单击虚拟教室卡。
1. 参加课程的方式有两种: 单击页面右上角的“开始”，然后单击播放器中的会话 URL，或者

   在页面中直接单击会话 URL。

完成课程后，您会收到成功完成课程的通知。

如果已为您启用 L1 反馈，则 Adobe Learning Manager 应用程序会发送提出 L1 反馈的提醒。

## 查看录制的虚拟教室会话 {#viewrecordedvirtualclassroomsessions}

如果想要收听已录制的虚拟教室会话，请单击虚拟教室课程。 您可以查看所有已录制的会话 URL。 前提是仅当会话主持人录制了会话时才适用。

>[!NOTE]
>
>通常，录制的会议 URL 会在会话完成后的两个小时反映在 Adobe Learning Manager 中。

## 使用Live Hub会话

如果公司为Learning Manager帐户启用了实时中心，则学习者可以使用实时中心使用虚拟教室课程。 如果您无法使用Live Hub，请联系您公司的管理员。 有关加入和参加会话的步骤，请参阅[以学习者身份加入会话](../../getting-started-with-live-hub/join-live-hub-session-as-a-learner.md)。
