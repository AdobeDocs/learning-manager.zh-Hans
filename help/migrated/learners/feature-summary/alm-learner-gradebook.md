# 面向学习者的Gradebook

## 使用gradebook开始课程

在Adobe Learning Manager中启用并看到课程的“Gradebook”后，**“Gradebook”**&#x200B;选项卡会显示在课程概述页面上。 可用于查看每个模块的加权分数、当前综合分数，以及是否已通过或仍需完成更多课程。

![](assets/image_0008.png)

## 有学分册可用时

当作者或管理员为课程启用了Gradebook可见性后，**Gradebook**&#x200B;选项卡会与&#x200B;**模块**、**备注**&#x200B;和&#x200B;**讨论**&#x200B;一起出现在课程播放器中。 如果未显示该选项卡，则表示尚未为此课程启用Gradebook，或管理员已禁用学习者可见性。 您的管理员仍然可以录制和看到分数。

在注册期间可随时打开&#x200B;**Gradebook**&#x200B;选项卡：

![](assets/image_0009.png)

* **开始之前：**&#x200B;注册后，您会看到可评分模块的完整列表，包括它们的重量百分比、每个模块的最大标记数以及作者设置的通过标准。 它精确地显示了课程的分级，然后您才能开始。
* **正在进行中：**&#x200B;当您完成模块并记录分数时，成绩单会更新，显示您到目前为止的得分，以及尚未尝试或等待评分的模块。
* **完成之后：**&#x200B;成绩单会在标题中显示所有最终模块分数、您计算的聚合课程分数以及&#x200B;**通过**&#x200B;的结果。

## 查看成绩单

* 从&#x200B;**我的学习**&#x200B;中选择您的课程。
* 从课程页面中选择“**Gradebook**”选项卡。

  gradebook标题显示：

  ![](assets/image_0010a.png)

* **通过条件：**&#x200B;所需的最低聚合分数和模块数
* 已完成所需模块的数目（在总数中）
* 您当前的&#x200B;**聚合分数**（以百分比表示）
* 您当前的课程状态： **未开始**、**完成挂起**、**已通过**&#x200B;或&#x200B;**失败**

标头下方的模块表显示了每个模块的以下列：

| **列** | **它显示的内容** |
|------------|-------------------|
| **模块** | 模块名称和类型 |
| **状态** | 您的此模块的完成状态或分数状态（请参阅下面的状态参考） |
| **重量** | 此模块在总分中所占的百分比 |
| **分数** | 此模块的分数（例如，40/100） |
| **贡献** | 此模块到目前为止已添加到总分中的实际百分点 |

## 从“模块”选项卡中查看模块重量

您也可以从&#x200B;**模块**&#x200B;选项卡中查看每个模块的权重，而无需打开成绩单。

从课程页面中，选择&#x200B;**模块**&#x200B;选项卡。

![](assets/image_0011.png)

**模块**&#x200B;选项卡显示每个模块的重量百分比以及完成课程所需的模块数量。

## 多次尝试的模块分数

如果模块允许多次尝试，则成绩单中显示的分数取决于课程作者对模块进行配置的方式：

* **最高：**&#x200B;显示任何尝试中的最佳分数。 在以后的尝试中得分较低并不会降低您录制的得分。
* **最新：**&#x200B;始终显示您最近尝试的分数。 以后尝试的分数越低，则替换以前的分数。

## 了解模块状态

分级手册中的每个模块均显示以下状态之一：

![](assets/image_0012.png)

| **状态** | **这意味着什么** |
|------------|-------------------|
| **已完成** | 模块完成并记录分数 |
| **正在进行** | 模块已启动但尚未完成 |
| **未启动** | 模块尚未打开 |
| **失败** | 模块得分，且分数未达到模块通过阈值 |
| **等待审阅** | 模块已完成，但正在等待讲师或管理员评分 |
| **无重量** | 模块类型不支持评分（PDF、视频等）；不支持聚合 |

## 总分的计算方式

您的综合得分是每个得分模块的加权贡献总和：

（得分÷最高得分）×重量% =模块贡献

分级簿中的&#x200B;**贡献**&#x200B;列显示每个模块对当前聚合的贡献。 此计算中排除标记为&#x200B;**无重量**&#x200B;的模块。

并非所有模块的得分均相同。 模块得分为100分，模块得分为10分，两者都正确得分。 公式在应用重量之前将每个重量标准化。

## 查看和报告Gradebook分数

Adobe Learning Manager管理员可以查看课程中所有注册学习者的加权成绩单分数，按模块深入查看单个学习者绩效，下载筛选后的学习者成绩单，并在内容审核记录报告中跟踪成绩单配置更改。

## 查看课程的分级表

为课程启用Gradebook后，打开课程时，左侧导航栏的&#x200B;**“报告”**&#x200B;下会显示新的&#x200B;**L2反馈 — Gradebook**&#x200B;部分。

* 以管理员身份登录Adobe Learning Manager 。
* 在左侧导航栏中，选择&#x200B;**课程**&#x200B;并打开要审阅的课程。
* 在课程导航中，在&#x200B;**报告**&#x200B;下选择&#x200B;**L2反馈 — Gradebook**。 将打开&#x200B;**活动反馈分级簿**&#x200B;页面。

![](assets/image_0013.png)

它显示了：

1. 课程的通过标准（所需最低模块和最低综合分数）
2. 用于按等级查看学习者的筛选器行： **已通过**、**失败**&#x200B;或&#x200B;**等待完成**
3. 汇总分数公式：每个模块的汇总分数= Σ（实现的分数÷最大分数）×权重
4. 显示每个学习者的&#x200B;**汇总分数**&#x200B;及其对于每个可评分模块分数的学习者列表
5. 当课程有多个实例时，可通过实例下拉菜单在课程实例之间切换

尚未尝试任何得分模块的学习者在得分列中显示破折号。 不支持计分、PDF、视频、音频等等的模块不显示为分数列。

## 查看单个学习者的分数

在&#x200B;**活动反馈分级簿**&#x200B;中，选择学习者的姓名。

![](assets/image_0014.png)

单个学习者视图会显示：

1. 学习者的姓名、电子邮件和状态（**完成挂起**、**已通过**&#x200B;或&#x200B;**失败**）
2. 总分以及学习者完成的所需模块数
3. 显示以下内容的模块表：模块名称、类型、是否必需、状态、权重、获得的得分以及对聚合的贡献

模块表包括所有可烧录和不可烧录模块。 可评分模块显示其分数和贡献情况。 不可分模块在“得分”和“贡献”列中显示破折号。

## 分数模块

管理员和讲师的评分行为与当前工作流程相比保持不变：

* 当基础内容报告分数时，**SCORM、AICC、xAPI和本机测验模块**&#x200B;会自动计分。
* 讲师或管理员从&#x200B;**出席情况与得分**&#x200B;页面中为&#x200B;**教室会话、虚拟教室会话和活动模块**&#x200B;评分。

## 下载课程的学习者成绩单

您可以通过以下两种方式之一，直接从Gradebook页面下载过滤到本课程的学习者成绩单：

* 在&#x200B;**活动反馈分级簿**&#x200B;中，选择页面右上角的&#x200B;**下载学习者成绩单**。
* 在管理员主页上，选择&#x200B;**报告**，然后选择&#x200B;**自定义报告**。 从可用报告列表中选择&#x200B;**学习者成绩单**。

有关更多信息，请参阅报告版本中的更改。

## 内容审查追踪事件

内容审查追踪可捕获两个特定于评级簿的配置事件：

| **事件** | **出现时** |
|-----------|---------------------|
| **已更新Gradebook** | 作者启用或禁用课程的Gradebook时 |
| **已更新模块权重** | 作者更改模块的权重百分比时 |

有关更多信息，请参阅报告版本中的更改。

使用这些条目来跟踪谁更改了分级簿配置以及更改时间，特别是在多个作者协作学习同一课程的环境中。

## 故障排除

**课程导航中不显示“L2反馈 — 分级簿”部分**

创建课程时，课程作者必须启用“Gradebook”。 确认作者已为创建课程启用了成绩单。 如果课程是在学龄表可用之前创建的，则无法追溯添加。 需要新课程版本。

**尽管模块已完成，但学习者的综合分数为0**

确认课程至少有一个分配了权重值的可评分模块。 如果学习者完成的所有模块均不可计分（PDF、视频、音频），则不会计算汇总分数。 此外，请确认已评分的模块未处于&#x200B;**等待审阅**&#x200B;状态。 未评分的模块将从汇总中排除，直到讲师输入分数为止。

**下载的学习者成绩单中缺少加权列**

此列仅在启用Gradebook且至少有一个模块保存了重量值时显示。 确认作者已启用分级簿并保存了总计100%的权重值。

**学习者已完成所有必需模块，但显示完成操作处于挂起状态**

一个或多个模块可能仍在等待讲师或管理员的分数（**等待审阅**&#x200B;状态）。 在所有必需模块都记录了完成和分数之前，课程无法完成。 输入&#x200B;**出席情况与得分**&#x200B;中的待处理分数以清除待处理状态。
