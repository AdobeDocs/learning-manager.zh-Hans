# 面向学习者的Gradebook

## 使用gradebook开始课程

在Adobe Learning Manager中启用并看到课程的“Gradebook”后，**“Gradebook”**&#x200B;选项卡会显示在课程概述页面上。 可用于查看每个模块的加权分数、当前综合分数，以及是否已通过或仍需完成更多课程。

![](assets/image_0008.png)

## 有学分册可用时

当作者或管理员为课程启用了Gradebook可见性后，**Gradebook**&#x200B;选项卡会与&#x200B;**模块**、**备注**&#x200B;和&#x200B;**讨论**&#x200B;一起出现在课程播放器中。 如果未显示该选项卡，则表示尚未为此课程启用Gradebook，或管理员已禁用学习者可见性。 您的管理员仍然可以录制和看到分数。

在注册期间可随时打开&#x200B;**Gradebook**&#x200B;选项卡：

![](assets/image_0009.png)

* **开始之前：**&#x200B;注册后，您会看到可评分模块的完整列表，包括它们的重量百分比、每个模块的最大标记数以及作者设置的通过标准。 它精确地显示了课程的分级，然后您才能开始。
* **正在进行中：**&#x200B;当您完成模块并记录分数时，成绩单会更新，显示您到目前为止的得分，以及尚未尝试或等待评分的模块。
* **完成之后：**&#x200B;成绩单会在标题中显示所有最终模块分数、您计算的总课程分数和&#x200B;**最终等级**&#x200B;结果。

## 查看成绩单

* 从&#x200B;**我的学习**&#x200B;中选择您的课程。
* 从课程页面中选择“**Gradebook**”选项卡。

  gradebook标题显示：

  ![](assets/image_0010a.png)

* **通过条件：**&#x200B;所需的最低聚合分数和模块数
* 已完成所需模块的数目（在总数中）
* 您当前的&#x200B;**聚合分数**（以百分比表示）
* 您当前的课程状态： **未开始**、**完成挂起**、**已通过**&#x200B;或&#x200B;**失败**

标头下方的模块表显示了每个模块的以下列：

| **列** | **它显示的内容** |
|------------|-------------------|
| **模块** | 模块名称和类型 |
| **状态** | 您的此模块的完成状态或分数状态（请参阅下面的状态参考） |
| **重量** | 此模块在总分中所占的百分比 |
| **分数** | 此模块的分数（例如，40/100） |
| **贡献** | 此模块到目前为止已添加到总分中的实际百分点 |

## 从“模块”选项卡中查看模块重量

您也可以从&#x200B;**模块**&#x200B;选项卡中查看每个模块的权重，而无需打开成绩单。

从课程页面中，选择&#x200B;**模块**&#x200B;选项卡。

![](assets/image_0011.png)

**模块**&#x200B;选项卡显示每个模块的重量百分比以及完成课程所需的模块数量。

## 多次尝试的模块分数

如果模块允许多次尝试，则成绩单中显示的分数取决于课程作者对模块进行配置的方式：

* **最高：**&#x200B;显示任何尝试中的最佳分数。 在以后的尝试中得分较低并不会降低您录制的得分。
* **最新：**&#x200B;始终显示您最近尝试的分数。 以后尝试的分数越低，则替换以前的分数。

## 了解模块状态

分级手册中的每个模块均显示以下状态之一：

![](assets/image_0012.png)

| **状态** | **这意味着什么** |
| ------------ | ------------------- |
| **已通过** | 模块完成并记录分数 |
| **正在进行** | 模块已启动但尚未完成 |
| **未启动** | 模块尚未打开 |
| **失败** | 模块得分，且分数未达到模块通过阈值 |

## 总分的计算方式

您的综合得分是每个得分模块的加权贡献总和：

（得分÷最高得分）×重量% =模块贡献

分级簿中的&#x200B;**贡献**&#x200B;列显示每个模块对当前聚合的贡献。 此计算中排除标记为&#x200B;**无重量**&#x200B;的模块。

并非所有模块的得分均相同。 模块得分为100分，模块得分为10分，两者都正确得分。 公式在应用重量之前将每个重量标准化。
