# 将您的AI客户端连接到Adobe Learning Manager

集成管理员必须先设置连接器。 如果您没有看到连接器，请与您的管理员联系。 **客户端仅适用于Adobe Learning Manager Ultimate层**。

管理员可以参考[将Adobe Learning Manager添加到您的AI客户端。](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)

1. 打开组织的AI客户端，例如Claude或ChatGPT Enterprise。
2. 在连接器列表中查找Adobe Learning Manager连接器。
3. 选择&#x200B;**连接**。
4. 出现提示时，使用您的企业身份登录。
5. 询问有关学习的问题。 如需创意，请查看&#x200B;**学习者提示示例**。

>[!NOTE]
>
>您只需登录一次。 您的请求以您自己的权限运行，因此您只能看到在Adobe Learning Manager中可以访问的内容。

## 故障排除

**找不到连接器**

请让您的管理员为您启用该连接器。

**AI客户端不记得您之前的问题**

每个请求都被视为新请求。 对话是否继续取决于您的AI客户端。 在下一个问题中重复详细信息。

**AI客户端未调用连接器**

根据您的需要命名问题，例如注册或课程主题。
