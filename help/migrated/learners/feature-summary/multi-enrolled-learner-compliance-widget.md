# “学习者合规性”小组件中的多注册课程

在Adobe Learning Manager中，学习者可以注册同一课程的多个实例。 “学习者合规性”小组件现在会列出每个具有截止日期的注册实例，因此学习者可以看到每个截止日期，而不仅仅是主要实例。

## 多注册课程的价格调整变化

更改之前，合规性小组件仅显示多注册课程的主要实例。 已注册多个实例的学习者无法看到小组件中其他实例的截止日期。

现在，合规性小组件会显示满足所有这些条件的所有实例：

* 学习者已完成实例注册。
* 实例具有截止日期。
* 学习者尚未完成实例。

每个条目都会显示实例名称，因此学习者可以区分相同课程的实例。 学习者选择条目时，Adobe Learning Manager会直接打开该实例。

例如，学习者完成了初始培训课程。 管理员随后在同一课程的9月版、10月版和11月版中注册学习者，并规定了最后期限。 合规性小组件列出了所有三个版本。

此小组件将在每个合规性类别中分别对每个实例计数： **超时**、**未来30天内即将到来的截止日期**&#x200B;和&#x200B;**按轨道运行**。

## 显示在合规性小组件中的实例

下表介绍了小组件处理每种注册情况的方式。

| 注册情况 | 显示在小组件中 | 备注 |
|--------------------------------------------------|-----------------------------------|---------------------------------------|
| 已注册，实例有截止日期，未完成 | 是 | 以实例名称显示 |
| 已注册，实例没有截止日期 | 否 | 仅显示具有截止日期的实例 |
| 实例已完成 | 否 | 未列出已完成的实例 |
| 在所有已注册的实例中完成 | 否 | 课程不再显示 |
| 一个实例具有截止日期，另一个实例没有 | 仅具有截止日期的实例 |                                       |
| 仅注册一个实例 | 是 | 小组件将显示该实例 |

有关API信息，请参阅[学习者应用程序中多注册实例的API支持](/help/migrated/api-changes-dec-2026.md#multi-enrolled-compliance-widget)。
