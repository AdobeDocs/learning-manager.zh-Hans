# 了解您的Virtual Coach性能报告

您的Virtual Coach报告卡显示了您在角色扮演中的表现，包括您涵盖的主题、沟通方式以及在下次尝试之前需要改进的特定领域。

每个完成的会话都会自动生成一个报告。 选择&#x200B;**查看分析**&#x200B;以在会话后立即访问它，或者随时从&#x200B;**我的学习**&#x200B;中的会话历史记录返回到它。 您还可以以PDF的形式下载您的报告，以便保存以作自己的记录，或与经理共享。

## 总分的计算方式

您的总分数是两个分量的加权组合：**知识分数**&#x200B;和&#x200B;**样式分数**。 创建方案的作者设置每个组件的权重；常见的配置是70%知识和30%样式，但具体情况因方案而异。

| 组件 | 它所衡量的内容 | 典型粗细 |
|---|---|---|
| 知识 | 您是否涵盖了所需主题并提供了准确的信息 | 70% |
| 样式 | 沟通方式 — 交付、速度、清晰度和信心 | 30% |

*您的报告卡显示为方案配置的确切权重，可能与此处显示的典型拆分不同。*

系统将在0至100分之间显示您的整体分数。 通过阈值由作者设置，并与您的分数一起显示。 如果您的分数达到或超过阈值，您将通过；否则，您可以重试会话。 如果某个必需主题配置为&#x200B;**建立或中断**，而您在对话期间根本没有处理该主题，则无论您在所有其他方面的表现如何，最终分数均为0。

## 知识分数

知识分数反映您在对话期间说的内容 — 无论您是否回答了作者为情境配置的主题。

### 主题细分

每个方案都有一组必需的主题。 您的成绩单会显示每个主题的单独分数和书面反馈，解释您覆盖的内容和错过的内容。 主题在报告底部的会话时间轴中以颜色标记，因此您可以确切地看到每个主题的讨论时间。

**发现调用场景的主题分数示例：**

| 主题 | 分数 | 摘要 |
|---|---|---|
| 开放与融洽 | 40 | 已确认可上班，但没有点名介绍自己或提及外展原因 |
| 临床可信度发现 | 60 | 已确定创作和审阅过程，但未明确承认角色的准确性问题 |
| 实施和资源评估 | 40 | 介绍了人员配备和时间表，但没有概述典型的设置步骤或确认利益相关者的参与 |
| 处理异议和风险 | 0 | 未邀请角色分担风险或犹豫不决，也未提供文档记录或缓解步骤 |
| 同意后续步骤 | 20 | 提供了项目时间表，但没有提出具体的低承诺后续步骤或安全口头协议 |

*每个主题分数都会准确显示您下次尝试之前要关注的对话部分。*

### 如何提高您的知识分数

报告中的每个主题部分都包含具体的、可操作的指导。 例如：

- **如果您在开放和融洽方面的得分较低：**&#x200B;请用名字问候角色，说明您的名字，简要提及外联原因，并通过一个简短的开头确认时间限制。
- **如果您在处理异议和风险方面的得分很低：**&#x200B;请明确邀请该角色分享疑虑，提出疑点时主动提供文档，并在继续之前确认问题已得到解决。
- **如果您在同意后续步骤方面得分较低：**&#x200B;建议一个清晰、承诺程度较低的后续步骤，要求通过电子邮件共享材料，确认首选时间和与会者，并寻求口头同意或不继续的明确原因。

## 样式分数

风格分数根据从您的音频自动测量的五个传递标准，反映您在对话期间的沟通方式。

**节奏**&#x200B;以每分钟字数(WPM)测量您的说话速度。 目标范围是140-180 WPM，速度足够快，听起来有信心，但速度足够慢，让人能够清楚理解。 在140 WPM以下，您的速度有点慢；在180 WPM以上，您的速度太快。 您的报告会显示您最慢和最快时刻的时间戳，以便您可以在会话录制中重放它们。

**清晰度**&#x200B;度量了您的演讲的可理解性。 得分达到90%或以上意味着人们可以很好地了解您；报告将此标记为通过或改进区域。

**填充词**&#x200B;是声音和短语，如“嗯”、“呃”、“喜欢”、“你知道”和“基本”。 频繁使用它们会降低可信度，分散对信息的注意力。 您的报告显示每个实例的总计数和时间戳。 通常，在3分钟的会话中，四个或更少的填充字是可接受的；五个或更少的填充字意味着您应该查看标记的时间戳，练习静默暂停，而不是用声音填充间隙。

**句子长度**&#x200B;度量您的句子是否简洁易懂。 目标范围是每个句子7-30个单词。 在7个词语下，句子可能听起来被剪裁或不完整；超过43个词语后，它们可能太长，可能会失去听者的注意力。 报告上的条形指示器显示平均数在该频谱中的位置。

**能量**&#x200B;可在整个对话中测量您的声音热情和信心。 该报告显示整个会话的能量时间表，颜色编码从低到高。 持续的高能量信号参与；特定时刻的下降值得在会话记录中回顾，以了解其原因。

## 会话录制和时间轴

“**会话录制**”部分将您的整个对话显示为带有同步时间轴的视频播放，由三个轨道组成：您的说话轮换、角色说话轮换以及每个点处理哪个必需主题，并用颜色标记以匹配主题分解表。 使用时间轴直接跳转到特定时刻，如错过主题或标记填充词时的时间戳。

## 最佳实践

- **首先查看得分最低的主题。** 其中的改进对您的整体分数影响最大。
- **使用主题时间轴检查计时。** 在对话中提早提出所需主题通常可以提升知识和风格得分。
- **重播您最慢的WPM时刻。** 节奏缓慢通常是由搜索正确的单词引起的；提前准备关键短语会有所帮助。
- **以低能量分数为提示来审阅你的开场白。** 能源往往在开始时是最高的，在中间是下降的；练习话题之间的过渡有助于保持势头。
- **重试角色扮演。** 请参阅[使用虚拟教练练习角色扮演](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md)。 每次尝试都会生成一份独立的新报告。 在接下来的课程中，使用您从一个课程中学到的内容。
