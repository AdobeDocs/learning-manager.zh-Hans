# 以经理身份查看外部学习请求

当团队中的学习者在Adobe Learning Manager中提交外部学习请求时，您会收到平台内通知。 您可以查看提交详细信息、批准或拒绝请求，并为学习者添加评论。

## 经理审核工作流程的工作方式

当学习者提交外部学习请求时，会发生以下情况：

1. 您会收到&#x200B;**应用程序内通知**，提示您查看提交内容。 提交内容会显示在经理信息板的&#x200B;**“外部学习”**&#x200B;选项卡中。
2. 您打开提交内容，审阅所有字段和作为证明的任何已上传文档，然后选择&#x200B;**批准**&#x200B;或&#x200B;**拒绝**。
3. 您可以添加学习者在收到通知时看到的&#x200B;**审阅评论**。
4. 学习者会收到包含您的决定的&#x200B;**平台内通知**。

如果您批准提交，则外部学习活动将添加到&#x200B;**管理员学习者成绩单**&#x200B;中，并显示在学习者的成绩单记录中。

## 审阅、批准或拒绝提交的文件

1. 以经理身份登录到Adobe Learning Manager 。

2. 在左侧导览窗格中选择&#x200B;**“外部学习”**。

3. 在提交列表中，选择要查看的请求。 提交内容按提交日期排序，最新内容位于顶部。

4. 查看完整提交内容：

   - 标题、描述、日期、持续时间和分数

   - 管理员配置的任何自定义字段

   - 附加的证明文档（如果提供）。 选择要查看或下载的附件

5. 选择&#x200B;**批准**&#x200B;或&#x200B;**拒绝**。

6. 在&#x200B;**查看注释**&#x200B;字段中，输入适用于该学习者的所有注释。 这是可选的，但在拒绝请求时建议这样做，以便学习者了解应更正的内容。

7. 选择&#x200B;**提交**。

学习者会收到有关您决定的应用程序内通知。 如果您已批准提交内容，则它现在会显示在“学习者成绩单”中。

## 管理提交队列

您的外部学习队列会显示您直接报告中的所有待处理和过去提交内容。

**按状态筛选**

使用&#x200B;**状态**&#x200B;筛选器缩小列表范围：

- **全部** — 显示每次提交，而不管状态如何

- **等待审阅 —**&#x200B;仅显示等待您审阅的提交

- **已批准 —**&#x200B;显示您已批准的提交

- **已拒绝 —**&#x200B;显示您已拒绝的提交

**搜索和排序**

- 使用&#x200B;**搜索**&#x200B;字段，按学习者姓名查找提交。

- 提交内容默认按提交日期排序，最新内容位于顶部。

### 审批路径规则

默认情况下，外部学习提交内容会路由到学习者的直属经理。 当学习者没有分配直属经理时，适用以下规则：

| **学习者有经理** | **学习者本身就是经理** | **提交被路由到** |
|---------------------------|-------------------------------------|---------------------------------------------------------------------------------------------------------------------|
| 是 | 否 | 直接经理（默认案例） |
| 是 | 是 | 直接经理（默认案例） |
| 否 | 否 | Root帐户用户（如果root帐户用户具有经理角色）；否则，提交内容将自动获得批准。 |
| 否 | 是 | 根帐户用户（如果根帐户用户具有经理角色）；否则，提交内容会路由到学习者。 |

如果您对特定学习者的经理分配有疑问，请联系您的帐户管理员。

## 外部学习报告和成绩单更改

学习者的外部学习提交在Adobe Learning Manager中获得批准后，该活动会添加到报告系统中，并显示在管理员学习者成绩单和学习者成绩单中。

### 外部学习如何在学习者成绩单中显示

**注意：**&#x200B;启用外部学习会将以下新列添加到管理员学习者成绩单中： **外部学习名称**、**完成注释**&#x200B;以及每个自定义字段的动态列。 自定义字段列始终显示在导出的末尾。 如果学习者成绩单数据输入到自动报告或BI工具中，请确保更新这些管道以处理其他列。

成绩单中仅显示&#x200B;**个已批准的**&#x200B;个外部学习提交内容。 成绩单导出中不包括&#x200B;**正在等待批准**&#x200B;或&#x200B;**已拒绝**&#x200B;状态的提交。

管理员学习者成绩单和学习者成绩单以不同方式处理外部学习标题：

- 在&#x200B;**管理员学习者成绩单**&#x200B;中，外部学习标题将放在现有&#x200B;**学习计划/认证/课程**&#x200B;列中，保持列结构与其他学习活动类型一致。

- 在&#x200B;**学习者成绩单**（学习者生成的）中，**模块**&#x200B;列之后立即添加了一个名为&#x200B;**外部学习名称**&#x200B;的新列。

提交获得批准后，管理员配置的自定义字段将在两个成绩单导出末尾显示为动态列。

外部学习行的管理员学习者成绩单中基于日期的筛选基于&#x200B;**完成日期**，该日期与批准日期相对应。
